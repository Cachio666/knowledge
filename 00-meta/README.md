# 00-meta —— 知识库自身

存放知识库的元信息，不是学习内容。

| 文件 | 用途 |
|---|---|
| [glossary.md](glossary.md) | 术语表中英对照。全库术语以此为准，避免同一概念多种译名。 |
| [index.md](index.md) | 全库索引，按域组织。 |
| [roadmap.md](roadmap.md) | 实施进度表，粒度到二级主题。 |

## 与其他域的关系

- **上游**：无。本域不承载知识内容，是知识库自身的记账层。
- **下游**：15 个知识域。每一篇文档的 `domain` 字段、每一个主题的完成状态、每一个术语的中英口径，最终都汇总到本域的三个文件里。
- **横切**：本域是**唯一不适用「一个知识点只有一处正文」的域**——它不产出知识，只索引知识。因此它与其他域之间是**引用关系而非内容关系**：`index.md` 指向各域目录，`roadmap.md` 记录各域进度，`glossary.md` 为全库统一译名。

写作规范见仓库根目录的 [CONTRIBUTING.md](../CONTRIBUTING.md)。
