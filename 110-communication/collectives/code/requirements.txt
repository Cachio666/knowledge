# ★★ **四类数字纪律**（`CONTRIBUTING` §2）：
#   · **规格值 / 引文** → `specs.py`（每条带 `# 来源：` + `[A-E]` 级 + 抓取日 + `# 同值位置：`）
#     ★★ 本主题**只有一条来源**：Thakur / Rabenseifner / Gropp 2005（IJHPCA 19(1):49–66，
