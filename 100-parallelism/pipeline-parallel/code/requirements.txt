# ★ **本域的两条通用纪律**（本主题同样适用）：

#     ★ 强制限定语：**「不是 NCCL，也不是真机」**。

# ★★ **本主题的定位**（与 `Makefile` **抬头那段**同一句，两处同步；

# ★★ **四类数字纪律**（`CONTRIBUTING` §2；域 README 的「代码约定」表）：
#    · **规格值** → `specs.py`（每条带 `# 来源：` + `[A-E]` 级 + 抓取日 + `# 同值位置：`）
#    · **推导值** → 由编号程序算出（**可手算复核**，并标为「推导值」）
#    · **引用值** → 外部来源的实测（**须注明「本仓库不复核其测量口径」**）
#    · **本机实测值** → 本机真跑的数（**须写 python3 版本**）
#    ★ **不得把推导写成实测**。
#    ★★ 本域另加两条落法：**所有数值常量取到 `< 2^53`**（`mutate.py` 的浮点变异是 `v + 1.0`，
#       大浮点数会吞掉它）；**幂次一律写成十进制字面量**（`_walk()` 不下钻 `BinOp`）。
#
# ★★ **本主题的判据不涉及 BLAS**（那是 `tensor-parallel` 的可移植性风险）——
#    这里的判据是**离散事件模拟 ↔ 闭式公式**对拍与**整数/算术**，
#    所以换机器**不会**因 BLAS 路径不同而误报。★ 但仍然标「本机实测值」（见上）。

# ★★ **「本机无 GPU」的限定语**：本机**没有多卡 / 没有 NCCL / 没有真实网络** ⇒
#    一切数值都是 `python3` 的**玩具规模**真跑。
