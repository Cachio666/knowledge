它们原先只存在于作者的 `/tmp/p100/`（**不入版本控制**，随时会被清掉），Chunk 0 把它们收进仓库。
**种子、初始化分布、重复次数、判据式都在脚本里** —— 读数字之前先读那一行是怎么算的。

- **不是编号程序**，不在任何主题的 `code/` 下，**不参与「文档数 = 编号程序数」的核对**

  可证伪的断言属于各主题 `code/` 下的编号程序，不属于这里。
- 运行环境（本机实测，即这些数字的测量条件）：**python3 3.13.5 + numpy 2.4.4**，
  macOS arm64（`macOS-26.4.1-arm64`），**10 核**，**无 GPU**。

  `probe_100a` / `probe_100d` / `probe_100e` / `probe_100f`（写作 `SEED = 100`）/ `probe_100h`。
  其余四个（`b` / `c` / `g` / `mp`）**不用随机数**。
  ⇒ ★ **同一个种子号在不同脚本里是【两条独立的随机流】**（各脚本的调用次数与顺序都不同），

## ★★★ `probe_100mp.py` 是「形态探针」，不是「知识探针」

`probe_100mp.py` 回答的是**「这台机器上能不能跑起两个真的进程并经 `socket` 收发」**，
**不回答任何关于并行策略的问题**。它的存在只为一件事：给计划 §1.1 的**方案甲**
（用多进程 loopback 真的跑集合通信）一个**实测的否决依据** ——
「形态可行，但**不作为编号程序的形态**」。

★ 它**不以非零退出码报告失败**（失败打印成一行 `形态：失败 —— …`，脚本仍退出 0）——
这是**形态探针**与**知识探针**的区别：后者的失败必须变成非零退出码。

## ★★ 「不可用的数」（**引用前必读**）

1. ★★★ **`probe_100mp.py` 打印的 loopback 带宽与 RTT —— 一个都不能引用。**
   - loopback **不代表任何真实链路**：没有网卡、没有 NVLink、没有交换机，也没有完整的协议栈路径；
   - 那两个数**主要量的是 Python 解释器搬字节的速度**（`recv` 循环在解释器里），不是链路指标；
   - ⇒ **不得**用于 `110-communication` 的任何带宽讨论，**不得**与 `20-gpu-architecture/interconnect/01`
     的 `450 GB/s` / `50 GB/s` 并列（那一节的纪律是「三种口径不能互换」，见该文 `:351`）。
   - ★ 实测（跑 4 次）：**换启动方式（`fork` vs `spawn`）的差最多 `1.95×`，4 次里有 3 次不到 `15%`**；
     而**跨次运行的抖动**（同一方式跑 4 次）约 `2.2×` —— ⇒ **抖动主要来自解释器，不来自启动方式**。
     ★ **README 刻意不抄那两个数**：它们每次运行都会变，抄下来只会变成一个新的「不可用的数」。
     （RTT 那一列同理：实测落在 **`~1e2 µs`** 量级，**没有任何可引用的含义**。）

2. **`probe_100g.py` 的 `G4` 用的是「引用值」。**
   `50 GB/s`（IB NDR 单向）与 `450 GB/s`（NVLink4 每方向）取自
   `20-gpu-architecture/interconnect/01-bandwidth-conventions.md:196,:231`。
   **本仓库不复核其测量口径** —— 它们是那份文档从厂商规范抄来的，本域只是**转发**。
   ★ 那一节自己的纪律：**做时间推导用单向 `450`，做能力对比用双向 `900`，两者不能互换**。

3. **`probe_100b.py` 的全部数字是「推导值」**（按写明的字节系数算出来的），
   **不是任何实现的实测**：本机**一个字节也没有真的分配过**。

4. **`probe_100f.py` 的 `D9` / `D21` 是「一个种子」的值**（种子 `100`）。
   换种子会得到别的分布 ⇒ 引用时**只写形态**（「发出恒等、接收不均」「`CF=1.0` 时必有丢弃」），
   **不要写单个数**（计划 §4 的 T56）。

5. **`probe_100a.py` 的 `D1` 不是「1 ulp」的复现。**
   计划记的行并行误差是 `2.220446049250313e-16`（**恰好 1 ulp**），本次是 `8.882e-16`（**4 ulp**）。
   ⇒ 本域纪律：**「机器精度档」是可引用的形态，「几 ulp」不是** ——
   它随形状、规模、BLAS 的累加顺序变。

6. **`probe_100e.py` 的 `E1` 没有复现「`CP=1` 比 `CP=2/4` 还大」。**
   本次 `CP=1` 与 `CP=2` 同为 `1.665e-16`。
   ⇒ **不要把那条观察当作规律**（它本来就只是「多一次重缩放 = 多一次舍入，方向随机」的一个实例）。
