# outlier 与误差传播：两种「极端值」现象，以及误差往哪走

> 「outlier feature」是**一个向量**（某个 feature 维在所有 token 上都大，占约 0.1% 的 feature 维）；「massive activation」是**一个标量**（数千万个 activation 里常常不到 10 个）。**它们不是同一现象**，而混为一谈是本域最常见的错误。误差则沿着「连乘的谱范数」走：**大于 1 就放大，小于 1 就衰减**。

## 0. 背景与动机

取一张 `(2048, 4096)` 的激活张量，对称 8 位量化，看四种粒度下的 SQNR（本机实测，判据见 §5）：

| 构型 | per-tensor | per-token | per-channel | per-group(128) |
|---|---|---|---|---|
| **干净**（`N(0,1)`） | 37.75 | 41.23 | 41.65 | 43.79 |
| **持久列 outlier**：4 列 ×100，**每个 token 上都有** | 29.81 | 34.75 | **41.76** | 43.06 |
| **6% 列 outlier**：同样 4 列，只在 6% 的 token 上 | 31.46 | **40.37** | 41.62 | 43.74 |
| **massive activations**：4 个**标量**（≈15000），落在 2 个 feature 维 | 20.35 | 48.52 | 52.89 | 60.32 |

第一行与第二行的差别是「**极端值在不在每一行都出现**」，第二行与第三行的差别是「**它在多少 token 上出现**」，第二行与第四行的差别是「**它是『一列的值都大』还是『几个位置的值特别大』**」。

这张表后面藏着一条工程上代价很高的混淆：**把第 4 行的现象当成第 2 行的现象处理**。前者有 4 个极端值、占 activation 位置的 **4.8e-5 %**、只覆盖 **3/2048 = 0.15% 的 token**；后者有 8192 个极端值、**覆盖 100% 的 token**。**换一个分母，两者的比例从「差 2000 倍」变成「只差 2 倍」**——而它们的成因、影响范围、和该用什么粒度去治，全都不同。

## 1. 原理

### 第一步：outlier feature 有形式化定义（引用）

LLM.int8()（arXiv:2208.07339v2 §1）给的定义是**三条同时成立**：

| 条件 | 阈值 |
|---|---|
| 幅值 | 某 feature 维上至少有一个值 `|α| ≥ 6.0` |
| 涉及多少层 | 该 feature 在 **≥ 25%** 的层里都是 outlier |
| 涉及多少序列 | 该 feature 在 **≥ 6%** 的序列维（token）上出现 |

（**2026-09-18 二次检索确认这三条阈值**；本主题实现者仍未逐字读原文。）

`6.0` 这个阈值的理由很具体：**把幅值 ≥ 6 的当 outlier 处理之后，perplexity 就不再退化**——它是用「精度不再掉」这个可观测的判据反解出来的，不是从分布形状推出来的。

关于它的稀疏性与位置（引用，来源为计划基线）：
- **13B 下每 2048 token 最多 150k 个 outlier，但只落在至多 7 个 hidden 维度**——占全部 feature 维度约 **0.1%**；
- **只出现在 attention 投影层（k/q/v/o）与 FFN 扩张层（第一子层）**；attention 函数本身与 FFN 收缩层没有；
- **符号结构**：几乎所有 outlier **严格非对称——要么全正要么全负**。这解释了为什么 zero-point（非对称）量化对它们特别有效；
- **突然涌现**：outlier 在 **6B → 6.7B 参数之间**从「偶发」变成「系统」——受影响层的比例 **65% → 100%**，受影响的序列维比例 **35% → 75%**。

**重要性对照**（引用）：去掉这些维度，平均 top-1 softmax 概率从约 **40% 掉到 20%**，perplexity 上升 **600–1000%**；而对照去掉 7 个**随机**维度，top-1 只降 **0.02–0.3%**、perplexity 只升 **0.1%**。

### 第二步：outlier 的持久性，以及它为什么让 per-token 失效

SmoothQuant（arXiv:2211.10438v7 §3）的原话大意是：**某通道有 outlier，则它在所有 token 上都出现**；token 内通道间方差很大，但同一通道跨 token 的幅值方差很小。

这条性质**决定了粒度该给哪一维**。回到 [02-granularity](02-granularity.md) 的第三步：scale 沿哪一维归约就吸收那一维的差异。

- outlier 在**列**（feature 维）上，而且**每一行都有**——那么**每行一个 scale** 的 `s_i` 在每一行都被同一个 outlier 抬高，**per-token 一点救不了场**；
- **每列一个 scale** 只把那一列抬高，其余列不受影响。

本机实测（§5 表 1 第 2 行）：持久列 outlier 下 per-token 34.75 dB，per-channel **41.76 dB**——而干净张量下 per-channel 是 41.65 dB，**即 per-channel 几乎完全隔离了损伤**。

**这就是 KIVI「K 必须用 per-channel」的理论根据**（[kv-cache-quantization](../kv-cache-quantization/)）。

> ⚠ **KIVI 的另一半不是这条机制**。它对 V 用的是 per-token，理由是 attention 分数高度稀疏、输出是少数重要 token 的 value 的加权组合——**那是关于 attention 结构的论证，不能从本文的粒度机制推出来**。

### 第三步：massive activations 是另一回事（引用 + 本机复现结构）

Massive Activations in Large Language Models（arXiv:2402.17762v2）原文写着 **"we show that massive activations are not the same as outlier features"**。两者的结构差异（**2026-09-18 二次检索确认**）：

| | outlier feature | massive activation |
|---|---|---|
| 是什么 | **向量**（某个 feature 维上的全部 token） | **标量**（一个 `(token, feature)` 位置） |
| 多少个 | 13B 下每 2048 token 最多 150k 个，落在 ≤ 7 个 hidden 维 | **数千万个 activation 里常常不到 10 个** |
| 多大 | ≥ 6.0 即计入；可达其它维度 20× | 比中位数大 **4 个数量级以上**；LLaMA2-70B 里绝对值可 **> 15000** |
| 在哪 | 遍布所有 token；约占 feature 维的 0.1% | **两个固定 feature 维 × 两类 token**（序列起始、第一个 `.` 或 `\n`） |

**该文的实测**：用 LLM.int8() 的定义在 LLaMA2-7B / 13B 上各识别出 10 / 25 个 outlier feature，**没有一个**与 massive activation 的 feature 维重合。

本机按这两条结构各构造一张张量（§5 表 1 的 R1/R3），量出「影响的格子有多大」：

| | 极端值个数 | 占 activation 位置 | 覆盖的 token | 覆盖的 feature 维 |
|---|---|---|---|---|
| R1（outlier feature 式） | 8192 | 0.098% | **100%**（构造上） | 4 / 4096 |
| R3（massive 式） | **4** | **4.8e-5 %** | **0.15%**（3/2048） | 2 / 4096 |

**两者在「feature 维」这个分母下只差 2 倍（0.098% vs 0.049%），在「activation 位置」这个分母下差 2000 倍。** 所以凡引用「占比」，**必须连分母一起写**。

**为什么这条区分有工程后果**：R3 的 4 个值把 per-tensor 的 scale 抬到 `15000/127 = 118`，于是 `N(0,1)` 的元素**全部被舍成 0**——本机实测，per-tensor 在**非极端元素**上的 SQNR 是 **0.00 dB**（信号功率 = 噪声功率），而 per-group(128) 是 39.97 dB。**一个 15000 的值能毁掉整张张量的分辨率**，而它的「占比」按任何口径都小到可以忽略。

### 第四步：误差沿深度怎么走

**引用部分**（全部来自计划基线，本主题实现者未逐字读原文）：

- **层间量化误差累积**，在量化层内近似指数增长，**且在未量化的后续层继续增长**（QEP，arXiv:2504.09629v3 Fig.2）。
- **一阶理论**：`δ_l = −Σ_{k<l}(∏_{s=k+1}^{l−1} J_s W_s)·J_k E_k X_k + O(max‖E_k‖²)`——**连乘项的谱半径 > 1 则指数放大**。
- 一项 2026 新预印本（arXiv:2608.08188v1，**未见同行评审**）报：传播项 `G_l·R_l` 在早/中/晚三阶段都主导总误差；**小模型中层持续放大（`G_l > 1`），大模型基本保持或轻微衰减（`G_l < 1`）**。

**本机合成实验**（§5 表 2，判据必须一起读）：12 层链、只量化前 3 层的激活、每层权重 `W_l = QR(高斯)·ρ^(1/L)`（**所有奇异值都等于 `ρ^(1/L)`**，所以 L 层的连乘谱范数恰好是 ρ）。

```
ρ = 0.90 : ‖δ_l‖/‖δ_3‖ = 0.9913  0.9826  0.9740  …  0.9240
           解析 ρ^(k/L)  = 0.9913  0.9826  0.9740  …  0.9240
ρ = 1.00 : 恒为 1.0000
ρ = 1.10 : ‖δ_l‖/‖δ_3‖ = 1.0080  1.0160  1.0241  …  1.0741
           解析 ρ^(k/L)  = 1.0080  1.0160  1.0241  …  1.0741
```

**实测与解析逐层吻合到 0.000%。** 结论：**连乘谱范数 > 1 则放大、< 1 则衰减、= 1 则保持**——这条一阶理论的判据在本机合成链上成立。

> ⚠ **一条必须写清楚的边界**：本机这条链是**纯线性、无归一化、无非线性**的。所以它**既不复现、也不否定** QEP 那条「在未量化的后续层继续增长」——那条描述的是**真实模型**上的观测，依赖非线性、归一化与残差结构。本机实测到的是：在这条链上，**偏差的绝对范数在放大/衰减，而相对误差 `‖δ_l‖/‖x_l‖` 在 9 个未量化层上保持不变**（极差 < 4e-7，ρ = 0.90 与 1.10 都是）。**本文因此不给「未量化层继续增长」这条结论下普适断言。**

### 第五步：两条不能外推的结论

**（1）残差连接的加性松弛，不得外推到量化误差。**

arXiv:2510.21770v2 Thm.2 说的是：残差连接把深度方向的误差从乘性累积**松弛为近似加性**——**但那是针对浮点舍入误差（`ε_mach` 一阶）的，不是 bit-width 量化误差。**

本机在合成残差链 `x_{l+1} = x_l + W_l x_l` 上测到相对误差**基本不动**（ρ=0.90 时末层/第 3 层 = **×1.007**、ρ=1.10 时 **×0.984**，而非残差的对照链是 **×1.000**）——**没有出现乘性放大**，看起来像「加性松弛」。

**但这个观测不能外推，本文也不外推它**，原因是可定位的：**同一条链上信号范数同时涨了 ×18.5–19.9**。也就是说，是分母涨得比分子快造成的「稀释」，而信号范数涨 20 倍本身是**未归一化的合成链的 artifact**，不是真实 Transformer 的行为。**本文把它记为「不可外推的观测」，不作为任何结论的依据。**

**（2）「误差会互相抵消」没有正面证据。**

计划基线明确记录：研究员检索未覆盖「层间对消」一侧，**但也未找到任何正面证据**。**本文因此不写「误差会互相抵消」。** 本机也不编造一条断言去「证明」对消不存在——那正是「要求实现者复现本域跑不了的东西」。

## 2. 执行映射

**（1）outlier 让「activation 比 weight 难」成为一条结构性事实**，三条机理：

1. **outlier 在 feature 维（矩阵的列）**——而权重侧的 per-channel 是硬件允许的，激活侧的 per-channel 会插进 GEMM 内维、硬件不可行，**只能退到 per-token**；
2. **权重分布平坦均匀、activation 长尾**；
3. 于是 activation 那一侧只能靠「per-token + 各种 shifting/scaling 技巧」绕着走。

**（2）「6% 的序列维」这个阈值不是随口定的。** 本机实测的两行对照给了它一个机制解释（§5 表 3）：

| | per-token 的非极端 SQNR | 相对干净张量（41.23） |
|---|---|---|
| 持久列 outlier（100% token） | 34.74 | −6.5 dB |
| 6% 列 outlier | **40.37** | −0.9 dB |

**outlier 只要不在每个 token 上都出现，per-token 就能靠「哪些行被污染」把它隔离掉。** 阈值定在 6% 而不是「有没有」，是因为 per-token 的隔离能力随污染比例下降。

**（3）误差传播那件事在真实系统里的落点是 layer-wise 的量化配置。** 既然误差沿连乘谱范数缩放，那么**同样位宽在不同深度上的代价不同**——这正是一条「统一位宽不如混合精度」的论证路线（[ptq](../ptq/) 与 [qat](../qat/) 会展开具体方法）。

## 3. 实现与演进

**第一步：混合精度分解（LLM.int8()）。** 既然 outlier 只占 0.1% 的 feature 维，那就**把这几个维度单独拿出来用 fp16 算**，其余用 int8。代价是引入了 mixed-precision 分支与相应的 kernel。

**第二步：per-channel 隔离（KIVI 的 K 侧 / KVQuant）。** 不换精度，只换粒度——把 per-token 换成 per-channel，误差就被限制在单个 channel 内。本机合成实验给出的机制与它一致（§1 第二步）。代价是 per-channel 无法流式：**所有已缓存的 K 都要被更新**，所以实践上要攒够 `R` 个 token 再量化一次（[kv-cache-quantization](../kv-cache-quantization/)）。

**第三步：把难度搬到别处（SmoothQuant 的路线）。** 不去「处理 outlier」，而是**用逐通道缩放把激活的量化难度等价迁移到权重上**，让 8 位激活可行。这是「训练无关」的，因为变换是数学等价的逐通道缩放、且可离线融合进前一层参数。

**第四步：把 outlier 单独存（KVQuant 的 dense-and-sparse）。** 1% 的 outlier 单独稀疏存，其余走常规量化。

**关于 massive activations 的处理，本文不给方案**——它的结构（几个固定维 × 少数 token 位）与 outlier feature 不同，本文只给出「它们是两回事」这条区分与实测的格子大小。

## 4. 踩坑与失败模式

### 4.1 把 massive activations 当成 outlier features

**现象**：文档写「LLM 的激活里有极少数极端值，占 0.1% 的维度，遍布所有 token」——**这一句把两种现象的各一半拼在了一起**，而且拼出来之后读起来毫无破绽。

**成因**：两种现象的「极端程度」和「稀疏程度」都超出直觉，而**「占比」这个词没有默认分母**。本机实测（§5 表 4）：

| 口径 | R1（outlier feature 式） | R3（massive 式） | 比值 |
|---|---|---|---|
| 占 **feature 维** | 0.098% | 0.049% | **2×** |
| 占 **activation 位置** | 0.098% | 4.8e-5 % | **2000×** |
| 覆盖的 **token** | 100% | 0.15% | **667×** |

**换一个分母，比例从 2000 倍变成 2 倍。** 两个数都对——这正是「两个数各自都对、来源都对、但不是同一个量」的形状。

**规避**：引用任何「占比」时**写出分母**；引用这两种现象时**先写清是「一个向量」还是「一个标量」**。判据可以用本文 §1 第三步那张表的四行：是什么形状 / 有多少个 / 多大 / 在哪。

### 4.2 用「全局 SQNR」评估被极端值污染的张量

**现象**：监控面板上 SQNR 显示 20.35 dB，看着「有点差但还行」，实际上下游已经崩了。

**成因**：**SQNR 是平方和之比，会被极端值自己主导。** R3 那 4 个 15000 的值贡献了 `4 × 15000² = 9.0e8`，而其余 8.4M 个 `N(0,1)` 只贡献 `8.4e6`——**分子被极端值占了 99%**。所以那个 20.35 dB 主要是在说「那 4 个值量化得不错」，而**非极端元素上的真实 SQNR 是 0.00 dB**。

**规避**：凡张量里有极端值，**把指标拆成「极端值上的误差」与「其余元素上的误差」两个**。本机程序 §A2 用的就是后一个（`|x| ≤ 10` 的子集）。这是一条**指标选择**的失败模式，不是实现错误。

### 4.3 把 KIVI 的「V 用 per-token」当成粒度机制的推论

**现象**：读完 [02-granularity](02-granularity.md) 的机制后写「outlier 在 channel 维所以 K 用 per-channel；同理 V 用 per-token 因为 V 的 outlier 在 token 维」。

**成因**：**KIVI 对 V 的理由不是这个。** 它的原文论证是「attention 分数高度稀疏、输出本质上是少数重要 token 的 value 的加权组合，per-token 量化把误差限制在单个 token 内」——**这是一条关于 attention 结构的论证，本文的粒度机制里没有任何东西能推出它。** 事实上 V cache **不显示 channel-wise outlier 模式**，所以从「outlier 在哪一维」这条路推不出「V 要用 per-token」。

**规避**：引用 KIVI 的 V 侧结论时，连它的理由一起引。**把两条不同的论证合并成一条，会得到一个在自己逻辑里自洽、但与原文不符的版本。**

### 4.4 把合成链上的传播观测当成真实模型的规律

**现象**：看到本机合成链上 `‖δ_l‖` 逐层乘以 `ρ^(1/L)`，就写「误差按连乘谱范数指数放大/衰减」。

**成因**：**教科书式的一阶理论确实是这样写的**，但真实模型不满足它的前提：本机这条链**纯线性、无归一化、无非线性**。实测到的两个差异都能定位：① 相对误差在未量化层**完全不变**（极差 < 4e-7），而不是「继续增长」；② 残差链上相对误差与 1 的偏离只有 ±1.6%，而**同一条链的信号范数涨了 20 倍**——那个「稀释」是未归一化的合成链的 artifact。

**规避**：合成实验的结论**只支撑机制**（「连乘谱范数决定缩放方向」），不支撑真实模型的误差演化。凡引用 QEP / arXiv:2608.08188 那一类真实模型上的观测，标为**引用值**，并写明「本仓库不复核其测量口径」。

**配套程序与 `verify.py` 的分工**（CONTRIBUTING §2 第三种形态）：编号程序在真 torch 上跑 `(2048, 4096)` 的合成张量与 12 层链（**本机实测值**）；`verify.py` 在默认 `python3` 下用标准库复算**计数与结构**那一部分（**推导**），规模不同 ⇒ 数字不同，**只有定性结构一致**。**两档不得互相背书。**

## 5. 实测数据

**测量条件**：CPU 型号 **Apple M1 Pro（10 核）**；macOS；`python3` **3.12.9**；`torch` **2.11.0**（每一格在 **2.6.0 / 2.7.1 / 2.8.0 / 2.11.0 / 2.13.0** 上**逐格一致**）；**CPU-only，无 GPU 数字**。
**未覆盖**：2.9.x / 2.10.x / 2.12.x。

> ⚠ **本表的四种构型都是合成的**（`code/03_outliers.py` §build_regimes）：R1/R2/R3 的规模按 §1 引用的结构性描述**仿造**，**与任何真实模型的具体数值无关**。它们只用来量「极端值影响的格子有多大」这个**机制**。**本机无 LLM 权重、无 GPU，perplexity 一律不测。**

**表 1：四种构型 × 四种粒度的 SQNR**（§A1；`[tokens, features] = (2048, 4096)`、对称 8-bit RTN、`QMAX = 127`、`G = 128`、切分沿 feature、种子 2026）

| 构型 | per-tensor | per-token | per-channel | per-group(128) |
|---|---|---|---|---|
| R0 干净 | 37.75 | 41.23 | 41.65 | 43.79 |
| R1 持久列 outlier（4 列，全 token） | 29.81 | 34.75 | **41.76** | 43.06 |
| R2 列 outlier（4 列，仅 6% token） | 31.46 | **40.37** | 41.62 | 43.74 |
| R3 massive activations（4 个标量） | 20.35 | 48.52 | 52.89 | 60.32 |

**判据**：SQNR = `10log10(Σx²/Σ(x−x̂)²)`；R1/R2 的 outlier 列固定在**前 4 列**（0.098% 的 feature 维），幅值为 `N(0,2) ± 6`；R2 的污染行是**随机 6%**（`randperm` 取前 122 行）；R3 的 4 个值（±15000）落在 `(0,7) (1,7) (2,7) (0,2049)`。

**表 2：只看「非极端元素」时的附带损伤**（§A2；判据：`|x| ≤ 10` 的子集上的 SQNR）

| 构型 | per-tensor | per-token | per-channel | per-group(128) |
|---|---|---|---|---|
| R0 干净 | 37.75 | 41.23 | 41.65 | 43.79 |
| R1 持久列 outlier | 29.80 | 34.74 | **41.75** | 43.05 |
| R2 列 outlier（6% token） | 31.46 | **40.37** | 41.62 | 43.74 |
| R3 massive activations | **0.00** | 28.18 | 32.54 | 39.97 |

**表 2 才是能看出失败的那张。** R3 的 per-tensor 在全局 SQNR（表 1）上是 20.35 dB，看起来只是「有点差」；**在非极端元素上是 0.00 dB**——`scale = 15000/127 = 118`，`N(0,1)` 的元素被舍到 0，误差就是信号本身，信号功率 = 噪声功率。判据：`round(m/s).abs() < 0.5` 的元素占非极端元素的 **99% 以上**。

**表 3：outlier 的持久性决定 per-token 能不能救场**（§A2 的两行之差）

| 构型 | per-token 的非极端 SQNR | 相对 R0（41.23） |
|---|---|---|
| R1：outlier 在 **100%** 的 token 上 | 34.74 | −6.5 dB |
| R2：outlier 只在 **6%** 的 token 上 | **40.37** | −0.9 dB |

**表 4：两种现象的「格子」大小**（§A5；判据：阈值 `|x| > 5`（R1）/ `|x| > 100`（R3），「覆盖的 token」= 该行至少含一个极端值）

| | 极端值个数 | 占 activation 位置 | 覆盖的 token | 覆盖的 feature 维 |
|---|---|---|---|---|
| R1 | 8192 | 0.098% | **99.0%** | 4 / 4096 = 0.098% |
| R3 | **4** | **4.8e-5 %** | **0.15%** | 2 / 4096 = 0.049% |

> ⚠ R1 的 99.0% 而不是 100%：**按构造**它在全部 2048 个 token 上都有 outlier 列，只是赋值本身带 `N(0,2)` 抖动、少数值没越过 `|x| > 5` 这个阈值。**构造事实与阈值判据必须分开写。**

**表 5：误差传播的乘性律**（§B1；12 层链、只量化前 3 层的激活、每层 `|W_l|₂ = ρ^(1/L)`、种子 7）

| ρ | `‖δ_4‖/‖δ_3‖` | `‖δ_12‖/‖δ_3‖` 实测 | 解析 `ρ^(9/12)` | 最大相对差 |
|---|---|---|---|---|
| 0.90 | 0.9913 | 0.9240 | 0.9240 | 0.000% |
| 1.00 | 1.0000 | 1.0000 | 1.0000 | 0.000% |
| 1.10 | 1.0080 | 1.0741 | 1.0741 | 0.000% |

**逐层吻合到 0.000%。** 而同一批实验里，**相对误差 `‖δ_l‖/‖x_l‖` 在 9 个未量化层上的极差 < 4e-7**（ρ = 0.90 与 1.10 都是）——**绝对范数在缩放，相对误差不动**。这就是 §1 第四步那条边界的实测依据。

**表 6：残差链上的「稀释」（§B3；`x_{l+1} = x_l + W_l x_l`，判据同上）**

| ρ | 非残差：相对误差 第 3 层 → 末层 | 残差：第 3 层 → 末层 | 残差链的信号范数变化 |
|---|---|---|---|
| 0.90 | 0.2917 → 0.2917 (×1.000) | 0.2869 → 0.2889 (×1.007) | **×18.5** |

## 6. 小结与延伸

三条可复用的结论：

1. **outlier feature 与 massive activation 不是同一现象，而混为一谈的代价是工程方案选错。** 前者是一个**向量**（某个 feature 维在所有 token 上都大，约 0.1% 的 feature 维），后者是一个**标量**（数千万个 activation 里不到 10 个）。本机量出的「覆盖的 token」比例是 **99.0% vs 0.15%**。**引用任何占比都要连分母一起写**——换分母，两者的比例从 2000 倍变成 2 倍。
2. **outlier 的持久性决定粒度该给哪一维。** 它在每一行都出现时，per-token 完全救不了场（34.74 vs per-channel 41.76 dB）；只在 6% 的 token 上出现时，per-token 就能隔离它（40.37 dB）。**判据是「污染比例」，不是「有没有污染」。**
3. **误差沿深度按连乘谱范数缩放：> 1 放大、< 1 衰减、= 1 保持。** 本机合成链上与解析式**逐层吻合到 0.000%**。而**残差连接的加性松弛是针对浮点舍入误差的，不得外推到量化误差**；「层间对消」没有任何正面证据，不得写。

**这条主线在 §0.8 的三角上是哪条边**：本文主要落在**「粒度 vs scale 开销」**这条边的极端情形上——outlier 就是把这条边推到极限的数据：**同样的 scale 开销（per-token 与 per-channel 都是 `T` 个 scale），因为给错了维，差 20 倍以上的分辨率**。而 §1 第四步的传播部分是另一条独立的线：它讲的是**多花比特**（更高位宽 / 混合精度）在深度方向买到了什么。

延伸有三条。**往下**：outlier 的成因（为什么 6B 之后突然涌现、为什么只在 attention 投影层与 FFN 扩张层）本文只给了引用值，机制未定。**往旁边**：处理 outlier 的两条主路线——按维度隔离（粒度，[02-granularity](02-granularity.md)）与把难度搬走（SmoothQuant 的等价迁移，[ptq/03-awq-and-smoothquant](../ptq/03-awq-and-smoothquant.md)）。**往工程**：KIVI 在真实 KV cache 上把这条机制落成了一个非对称方案（K per-channel / V per-token），见 [kv-cache-quantization/02-kivi-asymmetry](../kv-cache-quantization/02-kivi-asymmetry.md)（本文不复述，此处回链）。
