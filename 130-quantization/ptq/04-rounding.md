# 舍入：AdaRound 属于 PTQ，以及「最近舍入不是最优」的两个判据

> 前三篇都在选「量化格点定在哪」；这一篇问的是**另一个自由度：把每个权重舍到哪个格点上**。**最近舍入（RTN）不是唯一选择**，而「随机舍入优于 RTN」这句话**在两个判据下给出相反答案**——本机实测：按**层输出 MSE** 判，随机舍入 **0/100** 一次都赢不了；按**任务准确率**判，**39/100** 能赢。**两个都对，因为它们不是同一个量。** 另外：**AdaRound 属于 PTQ，不属于 QAT**——它不训练任何权重，只要 1024 张**无标签**图。

## 0. 背景与动机

先摆清楚「舍入」这个自由度有多大。4-bit 量化一个权重 `w`，设它落在第 `k` 与第 `k+1` 个格点之间。**RTN 说：取更近的那个。** 但「更近」是**逐元素**意义上的最近——它对**整个网络的输出**并不最优。

AdaRound 论文表 1 的对照（**引用值**）直接指出了这一点：对 ResNet18 第一层做 4-bit，**100 次随机舍入中有 48 次比最近舍入的准确率更好**；最好的一次拿到 **63.06%** vs 最近舍入的 **52.29%**。全层 AdaRound 4-bit 达 **66.56%**，而 RTN 只有 **23.99%**。

**这是一个很强的结论**：如果「往哪舍」这件事有这么大的自由度，那「就近」只是一个方便的默认值，不是最优解。

**而本机要做的第一件事是把这句话的判据钉死。** 因为：

| 判据 | 随机舍入优于 RTN 的次数（本机 100 次） |
|---|---|
| **层输出 MSE** `mean((XWᵀ − XW_qᵀ)²)` | **0 / 100** |
| **任务准确率**（小 MLP，合成二分类） | **39 / 100** |

**⇒「随机舍入优于 RTN」在 MSE 判据下是错的、在任务判据下是对的。** 论文表 1 用的是**任务准确率**，所以它成立；把那句话不加限定地带到 MSE 上，就是错的。

本篇要回答：

1. 「最近舍入不是最优」到底成立在哪一个判据下？为什么？
2. AdaRound 怎么把这个离散决策变成可学习的？软舍入函数长什么样？
3. ★ 它凭什么是 **PTQ** 而不是 QAT？
4. 为什么本机复现不出 48/100 与 63.06%？

## 1. 原理

### 第一步：为什么「最近」在逐元素意义上是最优的

设 `w` 落在格点 `k` 与 `k+1` 之间，`t = w/Δ − k ∈ (0,1)` 是它的小数部分。两种舍法：

| 舍法 | 量化值 | 逐点平方误差 |
|---|---|---|
| 向下 | `k·Δ` | `(tΔ)² = t²Δ²` |
| 向上 | `(k+1)·Δ` | `((1−t)Δ)² = (1−t)²Δ²` |

`t² < (1−t)²` 当且仅当 `t < 0.5`。**⇒「就近」就是「逐点平方误差最小」的解。** 这不是巧合，是同一件事。

**所以只要判据是「逐元素 MSE」，RTN 就不可能被随机舍入击败。** 本机实测的 0/100 **不是巧合、不是样本不够**——它是上面这两行的直接后果。

### 第二步：那为什么任务判据下它会被击败

因为**任务损失不是逐元素 MSE 的和**。量化层的输出要经过后面所有层，而那条路径是**非线性、非凸、有大量平坦区与鞍点**的。逐元素最优的舍入组合，落在**任务损失的一个局部极小**上，但**不是全局极小**。

AdaRound 论文的表述方式是：**逐元素 MSE 最优 ⟹ 任务损失的一个局部最优，但不一定是更好的那个。** 于是「随机扰动一下舍入决策」有时能找到更低的点——**48/100 说的就是「有一半左右的随机扰动落在更好的点上」**。

> ⚠ **不要说「随机舍入比 RTN 好」。** 准确说法是：**在任务判据下，RTN 不是最优；随机舍入是一个能到达更好点的构造方式；而它显著差于 RTN 的情况同样存在**（本机 100 次里均值 0.9566 **低于** RTN 的 0.9570，因为分布是偏的——少数几次大幅领先，多数略差）。

### 第三步：AdaRound 怎么把离散决策变成可学习的

不能直接对「舍 0 还是舍 1」求导。AdaRound 的做法是引入一个**连续的松弛变量 `V`**，用一个**软舍入函数**把它映到 `[0,1]`：

```
h(V) = clip( σ(V)·(ζ − γ) + γ,  0, 1 )        ζ = 1.1,  γ = −0.1   （式 23，固定）
```

- `σ(V) = 1/(1+e^{−V})` 是 sigmoid；
- `(ζ − γ) = 1.2` 把 sigmoid 的值域从 `(0,1)` **拉宽**到 `(−0.1, 1.1)`；
- `clip` 再把它**压回 `[0,1]`**。

于是 `h(V)` 就是「把第 `k` 与第 `k+1` 个格点**按比例混合**」的连续插值：`h = 0` 取 `k`、`h = 1` 取 `k+1`。

**为什么要 `ζ/γ` 而不是直接用 `σ`？** 因为 `σ` 永远达不到 0 或 1。`clip` 之后，只要 `|V|` 足够大，`h(V)` 就**精确等于** 0 或 1——**量化决策能真正落到格点上**。本机实测：`h(−60) = 0.0`、`h(+60) = 1.0`、`h(0) = 0.5`。

**去掉 clip 会怎样**：本机实测，无 clip 时 `h(−60) = −0.1000`（**负值**）、`h(+60) = 1.1000`（> 1）。**它们已经不是合法的概率/插值系数了。**

### 第四步：正则项把 `V` 逼到 0/1

只最小化任务损失，`h(V)` 会停在 `(0,1)` 中间的某个值——那意味着**权重没有真的落到格点上**。所以 AdaRound 加一个正则：

```
f_reg(V) = Σ_V ( 1 − |2·h(V) − 1|^β )
```

- `h = 0` 或 `1` 时 `|2h−1| = 1` ⇒ 单项 = 0（**不罚**）；
- `h = 0.5` 时 `|2h−1| = 0` ⇒ 单项 = 1（**罚满**）。

**`β` 是退火参数**：论文说「前期 `β` 高允许 `h` 自由取值，后期 `β` 低逼 `h` 收敛到 0/1」。本机实测（对单点 `V = 2.0`，`h(2.0) ≈ 0.9669`）：

| `β` | 1.0 | 2.0 | 5.0 | 10.0 |
|---|---|---|---|---|
| `f_reg` | **0.086087** | 0.164763 | 0.362435 | 0.593511 |

**β 越小，f_reg 越小 ⇒ 同样的 `h` 被罚得更少。** 这看起来与「逼到 0/1」相反，但注意 `f_reg` 的形状：`β` 小时，**`h` 在 0/1 附近之外**的项被罚得少，于是优化更愿意**先把任务损失压下去**；`β` 大时，**任何偏离 0/1 都被重罚**，梯度全用来把 `h` 推向两端。**「β 低逼得更紧」说的是后者的效果。**

> ⚠ ★ **β 的退火区间与 λ（正则系数）的具体数值，论文正文未印**——原文只说 "we anneal the parameter β"。
> **不得编具体数字。** 本文只给上式与 `ζ = 1.1 / γ = −0.1` 这两个论文印出的常数。

### 第五步：★ 为什么这是 PTQ 不是 QAT

这条判定有三条依据，**全部来自论文本身**：

| # | 依据 | 含义 |
|---|---|---|
| 1 | 标题即 "Up or Down? Adaptive Rounding for **Post-Training** Quantization" | 作者自己归在 PTQ |
| 2 | **不训练任何权重**——只学每个权重的**舍入决策**；量化网格（`Δ`）**预先独立确定、之后固定** | 可学参数量 = 每个权重 1 个 `V`，而且它只决定「往哪舍」，不改连续值 |
| 3 | 只需 **1024 张无标签** ImageNet 图，**不用任务损失、不用标签** | 没有标签就不是「训练」意义上的监督学习 |

**第 2 条是最硬的一条。** QAT 的定义是「在训练过程中让网络**适应量化误差**」——它更新的是**权重本身**；AdaRound 的权重**一个都没动**，它只是在**已经定好的量化网格上**重排舍入决策。本机实测的预算也印证这一点：`10000` 步、batch size `32`、`1024` 张图——**这是「一次校准」的量级，不是「训练」的量级**（论文报告 ResNet18 单次约 10 分钟，GTX 1080 Ti）。

> ⚠ **不要因为「它要跑梯度下降」就把它归进 QAT。** 「用了优化器」不等于「在训练权重」。**判据是「更新的是谁」**：AdaRound 更新的是 `V`（舍入决策的松弛），权重是常数。

## 2. 执行映射

### 2.1 三个组件名与一个数值量级

- **量化网格 `Δ`** —— 由前三篇的校准方法**先定死**，AdaRound 不改它（这是它与 QAT 的分界）；
- **`V`（每权重一个）** —— 唯一被优化的张量；形状与权重相同；
- **`h(V)`** —— 前向时用 `round` 的「软版本」：`ŵ = Δ·(k + h(V))`；
- **量级**：`V` 初值取 0 时 `h(0) = 0.5`（权重量化到两个格点正中间）——**初始化就落在最不确定的位置**，这是一个刻意的选择。1024 张图 × batch 32 = 32 个 step/epoch，10000 步 ≈ 312 个 epoch（在 1024 张图上）。

### 2.2 与 QAT 的执行差异

| | AdaRound | QAT |
|---|---|---|
| 被更新的张量 | `V`（舍入决策） | **权重本身** |
| 量化网格 | **固定** | 可跟着权重动（LSQ 里 `s` 也在学） |
| 数据 | 1024 张**无标签**图 | 完整训练集 + 标签 |
| 步数 | 10k | 完整训练 schedule |
| 产出 | 一张**舍入表** | 一组新权重 |

## 3. 实现与演进

**第一代：RTN。** 逐元素最近舍入。**在逐元素 MSE 下它就是最优**（§1 第一步），所以「换一种舍入」的第一个动机只能来自别的判据。

**第二代：随机舍入（stochastic rounding）。** 按小数部分 `t` 的概率在 `k` 与 `k+1` 之间抽签。性质：**期望上无偏**（本机实测：2000 次平均与真值的最大差 4.5972e-03，落在单次舍入误差的量级内），但**单次方差更大**。**所以它在逐元素 MSE 判据下必然输给 RTN**（本机 0/100），**而在任务判据下有机会赢**（本机 39/100）。

**第三代：AdaRound。** 把「舍入」参数化成一个可学习的连续变量，用任务损失**直接**优化。**代价**：要为每个权重存一个 `V` 并跑梯度，比 RTN 贵得多；**收益**：论文表 1 的 66.56% vs 23.99%（全层 4-bit）。

**第四代：与其他技术的组合。** AdaRound 是**正交于**「改尺度」那一类方法的——它不动 `s`，只在给定网格上重排。这与 `03-awq-and-smoothquant` 的 `s` 搜索是两个不同的自由度。

## 4. 踩坑与失败模式

### 4.1 把「随机舍入优于 RTN」当成一条普适结论

**现象**：写「随机舍入比最近舍入更好」，或把它当成一条量化技巧。

**成因**：这句话**只在任务判据下成立**。在**层输出 MSE / 逐元素 MSE** 判据下，RTN 是定义上的最优（§1 第一步的两行不等式），随机舍入 **0/100** 一次都赢不了。

**规避**：引用时**必须写明判据**。本机的两组数（0/100 与 39/100）**不得并列成「估算 vs 实测」**——它们是**两个不同的量**（P9）。

### 4.2 把 AdaRound 归进 QAT

**现象**：文档分类里把 AdaRound 放进「量化感知训练」一章。

**成因**：它确实要跑 10000 步梯度下降，很容易被归到「训练」。

**规避**：用「**更新的是谁**」判定——AdaRound 更新的是 `V`（舍入决策），**权重一个都没动**，量化网格预先定死，而且**不要标签**。三条依据都在 §1 第五步。**标题里就写着 Post-Training。**

### 4.3 给 `β` 的退火区间或 `λ` 编一个数

**现象**：想写「β 从 20 退火到 2」、「λ = 0.01」这类具体值。

**成因**：这是「不编数字」这条纪律最容易破的地方——因为不写具体值，段落看起来「不够完整」。

**规避**：论文正文只说 "we anneal the parameter β"。**本文只写方向（前期高、后期低）与两个印出的常数（ζ = 1.1、γ = −0.1），不写区间与系数。** 判据：`specs.ADAROUND_UNPRINTED` 里记的就是「这两个量论文没印」这件事本身。

### 4.4 去掉 `clip` 之后 `h(V)` 不再是合法插值

**现象**：觉得 `clip` 是个无关紧要的数值保护，去掉试试。

**成因**：`ζ − γ = 1.2 > 1`，所以 sigmoid 的值域被**拉宽**到 `(−0.1, 1.1)`——**两端都越界**。不 clip 时 `h` 会取负值或大于 1，`ŵ = Δ·(k + h)` 落到格点之外。

**规避**：保留 clip。判据：本机实测无 clip 时 `h(−60) = −0.1000`、`h(+60) = 1.1000`；有 clip 时恰好 `0.0` / `1.0`。

### 4.5 期望本机复现论文的 48/100 与 63.06%

**现象**：拿一个小网络跑随机舍入，发现赢的比例对不上。

**成因**：论文的数字来自 **ResNet18 + ImageNet**，而且是**只量化第一层**的 4-bit 设置。**本机没有这两样东西**（无 ImageNet 数据集、无 GPU）。

**规避**：**把论文的数字标成引用值，把本机数字标成本机实测值并写明「测试集不同」。** 本机复现的是**定性结构**（任务判据下确实有随机舍入胜出），不是数值。**规模不同 ⇒ 数字不同。**

## 5. 实测数据

**测量条件**：Apple M1 Pro（10 核）/ macOS / **CPU-only，无 GPU 数字**；python 3.12.9；**torch 2.11.0**。五个解释器（2.6.0 / 2.7.1 / 2.8.0 / 2.11.0 / 2.13.0）都跑过；`2.9 / 2.10 / 2.12` 本机无解释器。数值逐条记在 `code/specs.py`。

> ⚠ **本机没有 ResNet18 / ImageNet。** 下表里凡标「引用值」的，**本仓库不复核其测量口径**。

### 5.1 AdaRound 的软舍入函数（判据：式 23，`ζ = 1.1`、`γ = −0.1`）

| `V` | −60 | −6.0 | −3.0 | −1.0 | **0.0** | +1.0 | +3.0 | +6.0 | +60 |
|---|---|---|---|---|---|---|---|---|---|
| `σ(V)` | ≈0 | 0.0025 | 0.0474 | 0.2689 | **0.5000** | 0.7311 | 0.9526 | 0.9975 | ≈1 |
| `h(V)` | **0.0000** | 0.0000 | 0.0000 | 0.2227 | **0.5000** | 0.7773 | 1.0000 | 1.0000 | **1.0000** |

`h(0) = 0.5`（因为 `0.5·(ζ−γ) + γ = 0.5`）；两端被 clip 到恰好 0 / 1。
**反例（去掉 clip）**：`h(−60) = −0.1000`、`h(+60) = 1.1000`。

### 5.2 正则项（判据：`f_reg(V) = 1 − |2h(V)−1|^β`，单项）

| `β` | `V = 0.0`（`h = 0.5`） | `V = 1.0`（`h = 0.7773`） | `V = 2.0`（`h = 0.9669`） | `V = 3.0`（`h = 1.0`） |
|---|---|---|---|---|
| 1.0 | 1.000000 | 0.445459 | **0.086087** | **0.000000** |
| 2.0 | 1.000000 | 0.692485 | 0.164763 | **0.000000** |
| 5.0 | 1.000000 | 0.947559 | 0.362435 | **0.000000** |
| 10.0 | 1.000000 | 0.997250 | 0.593511 | **0.000000** |

两处要看清：

- `V = 0` 时无论 `β` 取何值都是 1.0（**罚满**，因为 `h = 0.5`）；
- `V = 3.0` 时 `h` **已被 clip 到恰好 1.0**，于是 `|2h−1| = 1`、`1^β = 1`，**`f_reg` 对任何 `β` 都是 0**。

⇒ **「β 低逼得更紧」不是指「罚得更小」**：正相反，`β` 小时中间状态的罚更小（`V=1` 那列从 0.997 掉到 0.445），于是**任务损失有机会先把 `h` 推过 clip 边界**；一旦越过边界，正则项恒为 0，`h` 就锁死在 0/1 上。`β` 大时梯度几乎全部用来把 `h` 往两端拽。

### 5.3 ★ 两个判据下的「随机舍入 vs RTN」（**同一件事、两个不同的量**）

**判据 ①：层输出 MSE。** 权重 `W: [64, 49] ~ N(0,1)×0.2`，输入 `X: [256, 49] ~ N(0,1)`，4-bit（`qmax = 7`），逐元素按小数部分抽样。

| | RTN | 100 次随机舍入 |
|---|---|---|
| 优于 RTN 的次数 | —— | **0 / 100** |
| 最好的随机舍入 | 5.492080e-02 | ≥ 5.492080e-02（**从未更低**） |

**判据 ②：任务准确率。** 小 MLP（`64 → 128 → 128 → 2`）+ 合成二分类任务，Adam 训 600 步，**只把第一层量化到 4-bit**。

| | 准确率 |
|---|---|
| FP32 | 0.9600 |
| 第一层 4-bit RTN | **0.9570** |
| 100 次随机舍入：**优于 RTN 的次数** | **39 / 100** |
| 最好一次 | **0.9610** |
| 最差一次 | 0.9505 |
| 均值 | 0.9566（**略低于 RTN**） |

**⇒ 两个判据方向相反，且各自都对。** 均值低于 RTN 说明分布是偏的——少数几次大幅领先、多数略差；**「39/100 能赢」与「均值更差」可以同时成立**。

## 6. 小结与延伸

- 「舍到哪个格点」是**独立于「格点定在哪」的另一个自由度**；RTN 只是逐元素 MSE 下的最优，不是任务损失下的最优。
- **★ 「随机舍入优于 RTN」这句话必须带判据**：层输出 MSE 判据 **0/100**，任务准确率判据 **39/100**。本机还实测到均值略低于 RTN——「有胜出者」与「平均更差」可以并存。
- **AdaRound 属于 PTQ**：不训练权重（只学 `V`）、量化网格预先定死、只要 1024 张**无标签**图。标题里就写着 "Post-Training"。
- 软舍入 `h(V) = clip(σ(V)(ζ−γ)+γ, 0, 1)` 的 **`ζ/γ` 是论文印值**（1.1 / −0.1）；**`β` 的退火区间与 `λ` 论文没印，不得编**。
- `clip` 不是装饰：`ζ−γ = 1.2 > 1` 让 sigmoid 的值域被拉宽到 `(−0.1, 1.1)`，不 clip 时 `h` 会取负值或大于 1。

**延伸**：`qat` 主题里的 STE 与本篇是同一件事的两侧——STE 说「反传时把量化当恒等」，本篇说「把舍入本身参数化」；两者都面对同一个事实：**`round` 的导数是 0（几乎处处）**。而 `theory/01-error-bounds` 的 `Δ/2` 界则是 RTN 在逐元素意义上最优的另一面表述。
