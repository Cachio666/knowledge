# RMSNorm 与 LayerNorm：不变性的精确形态

> 两个算子常被一句「RMSNorm 就是去掉均值的 LayerNorm」带过。**本文不讨论那句话对不对**
> （它既不是判据也不是错），而是拆成三个**可判定**的问题：
> **哪一个不变性真的丢了**（实测：丢的是**平移**，`7.55e-15` vs `2.03`；
> 而**缩放**两者都有、`eps = 0` 时都 `< 1e-14`）；**`eps` 扮什么角色**
> （它**只**破坏缩放那一半：`1e-6 → 2.34e-07`、`1e-3 → 2.34e-04`，
> 对 LayerNorm 的平移偏差**精确无关**）；**「相等」的边界在哪**
> （论文逐字是**条件句**：均值为 0 时严格相等 —— 本文给出它的**充要闭式**
> `cos(LN, RMS) = σ/√ms`，并实测 `μ ≡ 0` 时两者差**恰好 `0.0`**）。

## 0. 背景与动机

一个 block 里有两个地方要做归一化：残差流上（`pre` / `post` / `final`，正文见
[`transformer/01`](../transformer/01-block-and-residual-stream.md)），以及每个 head 的 `q`/`k` 上
（**QK-norm**，正文见[本主题的下一篇](02-placement-and-qk-norm.md)）。而「用哪一种」这个问题
在工程上被简化成了一句话：**「现在都用 RMSNorm，因为它更省、效果一样」**。

这句话的**每一半**在本文里都要被换成可判定的形式：

- 「更省」——省的是**一个归约量**（`§2`：`2` 个统计量 vs `1` 个）。
  ⚠ **它的访存账不在本文**：归约的字节数与单遍/两遍的代价正文在
  `40-kernels/softmax-normalization/03-normalization-fusion.md:213-263`（正文在彼，此处回链）。
- 「效果一样」——**不是本文能回答的**（本域无 GPU、不训练模型）。本文回答的是它的**结构前提**：
  **丢掉平移不变性到底丢掉了什么、没丢掉什么**。

**为什么这件事值得单写一篇**：原论文的主张**只覆盖了一部分**，而转述通常把它扩大化。
本域实测能给出的三条精确形态（全部在 `§1`）：

| 不变性 | LayerNorm | RMSNorm | 破坏者 |
|---|---|---|---|
| **平移** `x + b` | **成立**（`7.55e-15`，且**与 `eps` 无关**） | **不成立**（`2.03`） | 不是 `eps` —— 是「不减均值」这个结构选择 |
| **缩放** `αx`（`α > 0`） | **成立**（`8.88e-16`） | **成立**（`1.33e-15`） | **`eps`** —— 两边的偏差都与 `eps` 同阶 |
| **「两者相等」** | 只在**均值为 0** 时（**恰好** `0.0`） | 同左 | 均值 |

★ **本表的第三列与第一列是本文与常见转述分歧最大的地方**：`eps` 常被说成「破坏了不变性」，
但它**只**破坏缩放那一半（`§1.2` 的 `A.5/A.6` 把这一条钉成断言）。

## 1. 原理

### 1.1 先明确一件事：本文不写公式

两个算子的**定义式**（含 `γ`/`β` 的去向）、Welford 递推、`Σx² − nμ²` 的灾难、
**`eps` 放在哪**带来的数值差异 —— 这些的正文**已在** `40-kernels/softmax-normalization/03-normalization-fusion.md:53-345`
（**公式在 `:55-71`**）。本文**不重写、不重推**（计划 §2 的边界表；域 README 的同一行）。

本文用的只有两条**可以直接说出口的性质**，以及它们推出的**关系式**（那才是本文的正文）：

- **性质 A（二次齐次）**：均方（RMS 的平方）是**二次齐次**的 —— 输入乘 `α`，均方乘 `α²`。
- **性质 B（平移不改方差）**：中心化后的离差平方和**不随平移改变**。

★★ **边界在哪**（这是本文与 `40-kernels/03` 的分工）：**算子本身**的定义与数值性质在彼；
**「哪个不变量在什么条件下成立」** 在本文。⇒ 本文出现的一切公式都是**量之间的关系式**
（**偏差的闭式**、**两个算子输出的夹角**、以及把两个算子写成「中心化向量 × 一个标量因子」
/「原向量 × 一个标量因子」这种**不带因子表达式**的形态），**没有一处是算子的定义式**。

★ **为什么这两种公式不算越界**（这条判断必须写出来，否则边界会被下一个人重新解释一遍）：
计划 §2 的禁区是**算子的公式**（以及它的 Welford 递推、`Σx²−nμ²`、`eps` 位置）；
而本文的主题是**不变性的精确形态** —— 不写「偏差是多少」就**没法**写出「哪个不变、哪个只在
`eps → 0` 时不变」。★ 计划 §3 Chunk 1 的裁决（**量级判据的证伪能力弱 ⇒ 能配闭式就配闭式**）
在这里同样适用：只写「偏差很小」的判据，换一批数据就不成立。

### 1.2 平移与缩放：两个不同的不变性，两个不同的破坏者

记行向量为 `x`（长度 `n`），归一化算子为 `f`。**不变性**的意思是
`f(T(x)) == f(x)`，其中 `T` 是平移或缩放。

**（一）平移。** 由**性质 B**，中心化后的离差平方和对平移免疫 ⇒ LayerNorm 的输出**逐位不变**
（实测 `7.55e-15`，那就是机器精度；★ 这条**与 `eps` 无关**，见下）。
而 RMSNorm 不减均值，平移会改变**均方**：`b` 与行均值同量级时，均方从 `ms` 变成
`ms + 2·mean(x)·b + b²` ⇒ 输出被整体缩放一个**不是 1** 的因子。
实测（`b = 100`、`eps = 1e-6`）：

```
LayerNorm  max|f(x+b) − f(x)| = 7.549517e-15      ← 机器精度档
RMSNorm    max|f(x+b) − f(x)| = 2.025136e+00      ← 不是一个「小量」
```

★ **判据写成不等式**（`< 1e-12` / `> 1.0`），**不写 `~1e-15` / `~2`**：
那两个数来自探测脚本的一次抽样（计划 §0.7-D 的 **D8** 记的是 `7.99e-15` / `2.006`），
**口径相同、抽样历史不同** ⇒ 可以比档位，不可以逐位对齐。

**（二）缩放。** 由**性质 A**，`α > 0` 时 RMSNorm 的分子分母同时乘 `α` ⇒ **精确不变**
（实测 `8.882e-16`）。LayerNorm 同理（中心化把 `α` 提出来，离差平方提出 `α²`）⇒
**两者都缩放不变**。★★ **这是本文要纠正的第一个直觉**：
「LayerNorm 等变、RMSNorm 不等变」在 `eps = 0` 时**两个都等变**；
**缩放不是它们的分界线**（`C.3` 把这一条做成断言）。

**（三）`eps` 出现之后。** `eps` 加在**归约出来的那个标量**上，于是 `α` 再也提不干净：
两边都变成「某个标量因子 × 输入」，而那个因子**不再与 `α` 无关**。

★ 两边**形状不同**这一点，在 `§1.3` 的两条闭式里看得最清楚：
LayerNorm 的闭式里 `eps` 被 `α²` **除掉**，RMSNorm 的闭式里 `eps` 与 `α²` 乘均方**相加** ——
⇒ 偏差**都是 `eps` 的函数、都在 `eps → 0` 时消失**，但**衰减方式不同**。
实测（`α ∈ {2, 50, 1000}` 取最大）：

| `eps` | LayerNorm | RMSNorm |
|---|---|---|
| `0` | `1.33e-15` | `8.88e-16` |
| `1e-6` | `2.34e-07` | `4.30e-08` |
| `1e-3` | `2.34e-04` | `4.30e-05` |

三档**严格递增**（`A.2a/A.2b`），且 `1e-3` 档 `> 1e-5`（判据 ②）。
★ 与探测脚本的记录（**D7**：`1e-6 → ~2e-7`、`1e-3 → ~2e-4`）**同档**，
且本机在 LayerNorm 上复现出 `2.342e-07` / `2.342e-04` —— 这两个数**对得上 D7**。

### 1.3 闭式：偏差不是「差不多大」，是**可手算的**

「偏差与 `eps` 同阶」这句话如果只写成量级，证伪能力很弱（改一点口径它照样成立）。
本文给的是**闭式**（`B.1`；★ 这两个式子是**偏差的表达式**，不是算子的定义式）：

- RMSNorm：记该行的均方为 `ms`、该行绝对值最大元为 `|x|max`，则

  ```text
  max|f(αx) − f(x)| = | α/√(α²ms + eps) − 1/√(ms + eps) | · |x|max
  ```

- LayerNorm：记该行的中心化离差平方平均为 `σ²`，则

  ```text
  max|f(αx) − f(x)| = | 1/√(σ² + eps/α²) − 1/√(σ² + eps) | · |x − μ|max
  ```

实测：`eps > 0` 的 6 组（`eps × α`）**逐行等于**闭式，以 `max|f|` 为单位的绝对差 `< 1e-12`
（实测 `~1e-17` 量级）；`eps = 0` 的 3 组两边都落在 `< 1e-14` 档（`B.1`）。
⇒ **结论**：偏差不是「某个抽样出来的数」，它**由该行的两个统计量唯一决定** ——
换一批数据、换一个种子，闭式跟着变，两者仍然相等。

★★ **一条量法口径的教训（`B.1b`）**：同一组比较若改用**相对误差**，最差是 `8.0e-09` ——
比机器精度差 7~8 个数量级，而且**阈值只能放到 `1e-6`**。原因不是闭式不准：
被测量的量 `|f(αx) − f(x)|` 本身只有 `|f|` 的 `~1e-8`，而 `f` 的每个值只有 `~1e-16`
的相对精度 ⇒ **这个差的相对精度被限制在 `1e-16 / 1e-8 ≈ 1e-8`**。
⇒ **「偏差的相对误差」这个量口径是坏的**；本文用的是「以 `|f|` 为单位的绝对差」。

### 1.4 「两者相等」的充要形态（多步推导）

论文逐字（`specs.RMSNORM_MEAN_ZERO_EQUALITY`，arXiv 1910.07467 §4）：

> "**When the mean of summed inputs is zero, RMSNorm is exactly equal to LayerNorm.**"

这是一句**条件句**。本文把它推成充要形态。记两个算子的输出分别为
`LN(x) = (x − μ)·g` 与 `RMS(x) = x·h`（`g`、`h` 是**正的标量因子**；★ **它们的表达式本文不写**，
定义在 `40-kernels/softmax-normalization/03:55-71` —— 下面会看到，**结论根本不依赖它们长什么样**）：

1. `⟨LN(x), RMS(x)⟩ = g·h·Σ_j (x_j − μ)·x_j`；
2. 而 `Σ_j (x_j − μ)·x_j = Σ_j x_j² − μ·Σ_j x_j = n·ms − n·μ² = n·σ²`（用 `Σx_j = nμ`）；
3. 两个输出的**范数**：`‖LN(x)‖ = |g|·√(n·σ²)`、`‖RMS(x)‖ = |h|·√(n·ms)`；
4. 于是夹角余弦

   ```text
   cos = ⟨LN, RMS⟩ / (‖LN‖·‖RMS‖)
       = (g·h·n·σ²) / (|g|·√(nσ²) · |h|·√(n·ms))
       = σ / √ms
   ```

   ★★ **`g` 与 `h` 全部消掉了。**

这个推导给出三条**可判定**的推论：

- **推论 1（与 `eps` 无关）**：`eps` 只通过 `g`、`h` 起作用 ⇒ `cos` **不依赖 `eps`**。
  实测：三个 `eps` 档（`0 / 1e-6 / 1e-3`）上 `max|cos − σ/√ms|` 分别 `4.996e-16` / `3.886e-16` /
  `4.441e-16`（`B.2`）—— 全在机器精度档，**没有随 `eps` 变化**。
- **推论 2（相等的充要条件）**：`cos = 1 ⟺ σ = √ms ⟺ μ = 0`。
  ★ 严格说「相等」还需要**两个方向的投影一致**（`cos = 1` 且范数相等）；
  而两个范数在 `eps = 0` 时**都恰好是 `√n`**（`n = 512` 时 `22.627417`，实测相对误差
  `2.220e-16`，`B.2b`）—— 这是「两个算子都把这一行投到同一个球面上」的直接后果。
  ★ 正因为**共用一个球面**，「两个算子差多少」才**只**是一个夹角问题（`B.2` 的闭式）。
  ⇒ **`μ = 0 ⟺ 两个算子相等`**，一字不差地对应论文那句原文。
- **推论 3（论文里两个 `hypothesize` 的位置）**：原文用 `hypothesize` 的地方**有两处、是两个主张**：
  Abstract 说的是 re-centering invariance **`is dispensable`**（可省），
  §4 说的是 **`the re-scaling invariance is the reason for success of LayerNorm, rather than
  re-centering invariance`**（才是成功的原因）。
  ⇒ ★ 引用时**必须指明是哪一处**；而**转述成「已证明」两处都不行**（`specs` 里两条都逐字钉住）。

**实测（`B.3`）**：把行**构造成**成对 `±v`（于是行和**恰好**是 `0.0`，实测 `max|mean| = 0.000e+00`），
两个算子的输出差 **恰好 `0.0`**（`eps = 0` 与 `1e-6` 两档都是）；而对照组（`mean ≈ 5`）
同一个量是 `2.756582`。

★★ **这条「恰好 0.0」的口径必须写出来**（`00-meta/glossary.md:240` 逐字：「`maxdiff == 0.0`
有**两种相反含义**」）：它不是「测出来的精确」，也**不是**「两边共用一份代码」，
而是**第三种** —— 两条**不同的实现**（程序的 `D.9` 用 AST 证明它们互不调用、源码不同），
在 `μ ≡ 0.0` 时**执行同一批标量运算**（`x − μ` 逐位等于 `x`）。
⇒ 它是**恒等式**。真正「测出来」的量是 `A.3/A.4` 的两条不等式与 `B.2` 的闭式。

## 2. 结构上差在哪（★ 不是访存账）

**（组件一）残差流的一行**（形状 `(N, D)` 里的一行）与**（组件二）每个 head 的 `q`/`k` 的一行**
（形状 `(H, S, d_h)` 里的一行）—— 归一化作用的对象就是这两种，「用哪个算子」的差别也落在它们上面。

**差的是归约量的个数**（`B.4`，返回值元组的长度把这一条钉住）：

| 算子 | 归约量 | 个数 |
|---|---|---|
| LayerNorm | 均值（`μ`）+ 离差平方平均（`σ²`） | **2** |
| RMSNorm | 均方（`ms`） | **1** |

这是「去掉均值」这句话**唯一可机械判定**的内容（`B.4`）。它的**代价**（少一次归约省多少字节、
单遍与两遍在什么形状下才真的省带宽）**正文不在本文** —— 在
`40-kernels/softmax-normalization/03:213-263`（正文在彼，此处回链）。
★ 本域**不重复**那份账：它是 kernel 侧的，而且那里的结论有一条很容易被跳过
（一行放得进 shared memory 时，两遍法的第二遍读的是**片上副本**、不产生额外显存流量）。

**数值量级**（本文自己的、可手算的）：

- 两个算子的输出范数（`γ = 1`、`β = 0`、`eps = 0`）**都恰好是 `√n`**：
  `n = 512` 时是 `22.627417`（实测相对误差 `2.220e-16`）。
- 它们的夹角由 `cos = σ/√ms` 给出；本机那批数据上 `cos` 的最小值是 **`0.479075`**
  （即最大夹角约 `61.4°`）—— ⇒ 「两个算子的输出差多少」是一个**每行都不同、且可以有几十度**的量，
  不是一个小修正。

## 3. 实现与演进

**真实模型把 `eps` 取在哪一档**（`B.5`；来源：两份 `config.json`，**经 `hf-mirror.com` 镜像取得**）：

| 模型 | `rms_norm_eps` | 缩放不变性的偏差（`α = 2`） |
|---|---|---|
| Llama-3-8B | `1e-05` | `2.150e-07` |
| Qwen3-30B-A3B | `1e-06` | `2.150e-08` |

★ 两个数是**确定的**：偏差与 `eps` 成**正比**，比值 `10.000`（`eps` 差 10 倍）——
这就是「偏差与 `eps` 同阶」的量化形态。
★ 两个模型的 config 里字段名都是 `rms_norm_eps`（逐字计数各 **1** 次），
而 `layer_norm_eps` 各 **0** 次。⚠ 本域**只记字段名与取值**，
**不据此推断「这两个模型内部用的是哪个算子」**（那是把字段名读成机制从句，本库禁止）。

**⇒ 这条账的意义**：真实模型的 `eps` 落在 `1e-6 ~ 1e-5`，对应偏差 `1e-8 ~ 1e-7` ——
**数学上不精确、工程上可忽略**。而 `1e-3` 那一档（偏差 `~2e-4`）已经不是可忽略的量级
（本机 `α = 2` 时 LayerNorm 到 `1.756e-04`）—— ★ 这条正是判据 ② 要求「三档严格递增」的理由：
**`eps` 的取值在真实范围内是有后果的，只是后果很小**。

## 4. 踩坑与失败模式

### 4.1 把「没有平移不变性」说成「不等变」（把缩放当成两者的分界）

- **现象**：写「LayerNorm 等变、RMSNorm 不等变，这就是它们的区别」。
- **成因**：「等变」在中文转述里同时指**缩放**与**平移**两件事，而只有后者成立。
  ★ 这个错误**本域探测阶段真的犯过一次**：控制者先预期「LayerNorm 不缩放等变」，
  实测 `2.65e-07` 说明它在 `eps = 0` 时**是**等变的（见 `probes/probe_80b.py` 的模块头）。
- **规避**：分辨率的做法是**分别写两条不等式**：平移（`< 1e-12` / `> 1.0`）与缩放
  （两者都 `< 1e-14`）。配套程序 `A.1` / `A.3` / `A.4` / `C.3` 就是这四条。

### 4.2 把 `eps` 说成「一切不变性的破坏者」

- **现象**：写「有了 `eps` 就没有不变性了」。
- **成因**：`eps` 确实破坏缩放不变性（`1e-3` 档到 `2e-4`），但**平移那一半与它无关**：
  LayerNorm 的平移偏差在 `eps = 0` 与 `1e-3` 下**完全相同**（实测三档极差 `0.00e+00`），
  而 RMSNorm 的平移偏差在 `eps = 0` 时**仍然是 `2.025136`**（`C.1`）——
  `eps` 对它的影响只占自身 `8.6e-06`。
- **规避**：`A.5`（LayerNorm 精确无关）与 `A.6`（RMSNorm 三档都 `> 1.0`）把两半分开断言。

### 4.3 把「偏差随 `α` 单调」当成直觉

- **现象**：写「缩放得越狠，偏差越大」。
- **成因**：偏差在 `α` 上**不是单调的**（`C.2`，`eps = 1e-3` 固定）：

  | `α` | `1e-3` | `1e-2` | `0.1` | **`1`** | `2` | `50` | `1000` |
  |---|---|---|---|---|---|---|---|
  | RMSNorm 偏差 | `2.3048` | `0.3502` | `4.25e-03` | **`0.0`** | `3.23e-05` | `4.30e-05` | `4.30e-05` |

  两头都「大」，但原因**相反**：`α = 1` 时**恰好 0**（那是不变性的定义）；
  `α → 0⁺` 那一端升到 `2.3048` ≈ `|f(x)|` 的 `0.82` 倍 —— 因为 `α√ms ≪ √eps` 之后
  `eps` 成了主项、输出趋于 `0`，**那是尺度塌缩，不是不变性被破坏**。
- **规避**：判据 ① 的 `α` 阶梯**不含 `α = 1`**（含它会让偏差恒为 `0.0` —— 一条**恒真断言**）；
  配套程序把这一条单独写成 `C.2b`。

### 4.4 用「偏差的相对误差」这个量口径

- **现象**：写「闭式与实测相对误差 `1e-8`，说明闭式不够精确」。
- **成因**：被测量的量本身是两个相近大数之差（`B.1b`），它的相对精度**结构性**地差
  `~|f| / 偏差` 个数量级。换阈值无济于事。
- **规避**：改成「以 `|f|` 为单位的绝对差」（本机 `~1e-17`）。★ 判据表里这条写成通用规则。

## 5. 判据表

| 可机械判定的条件 | 结论 |
|---|---|
| `eps = 0` 时 `f(αx)` 与 `f(x)` 的最大逐元素差 | **两个算子都** `< 1e-14`（本机 `8.882e-16` / `1.332e-15`）⇒ **缩放不是两者的分界** |
| 平移 `x + b`（`b` 与行均值同量级）后的最大逐元素差 | LayerNorm `< 1e-12`（本机 `7.550e-15`）；RMSNorm `> 1.0`（本机 `2.025136`）⇒ **分界线是平移** |
| 平移偏差 × `eps` 三档的极差 | LayerNorm **精确为 0**（本机 `0.00e+00`）⇒ 平移不变性**与 `eps` 无关**；RMSNorm 三档都 `> 1.0`、`eps` 的贡献 `< 1%` |
| 缩放偏差 × `eps` 三档（`0 / 1e-6 / 1e-3`） | **严格递增**（本机 LN `1.33e-15 → 2.34e-07 → 2.34e-04`），且 `1e-3` 档 `> 1e-5` ⇒ **`eps` 是缩放不变性的破坏者** |
| 偏差想要一个可证伪的判据 | 必须配**该行统计量的闭式**（`§1.3`）；只写「与 `eps` 同阶」的判据**换一批数据就不成立** |
| 报「偏差的相对误差」 | **先问这个量是什么**：两个相近大数之差的相对精度被 `~|f|/偏差` 限死（本机 `8.0e-09`）⇒ 改用「以 `|f|` 为单位的绝对差」 |
| 行均值**恰好**为 0（构造，如成对 `±v`）时两个算子的输出差 | **恰好 `0.0`** —— 这是**恒等式**（论文逐字的条件句），**不是**机器精度比较；报它必须同时报对照组（`mean ≠ 0` ⇒ `2.756582`） |
| 想判「两个算子差多少」 | 用闭式 `cos(LN, RMS) = σ/√ms`（**与 `eps` 无关**；本机 `cos` 最小 `0.479075`）；`μ = 0 ⟺ cos = 1` |
| 想知道两个算子的输出**差在哪** | 它们**共用一个球面**（`eps = 0` 时范数都是 `√n`，实测 `2.220e-16`）⇒ 差**只**是一个夹角：`cos = σ/√ms`（`B.2b` + `B.2`） |
| 要区分「哪一条不变性丢了」 | **只能**用两条**不等式**分别写（平移 / 缩放）；`eps` 对两条的作用**不同**（一条是零、一条是同阶） |
| 引用 RMSNorm 论文的「re-centering 可省」 | 原文用 **`hypothesize`**，且**两处是两个主张**（Abstract：`is dispensable`；§4：`is the reason for success`）—— 不得转述成「已证明」，且要指明是哪一处 |
| 想知道两个算子的**定义式**、Welford 递推、`Σx² − nμ²`、`eps` **位置**的数值差异 | **不在本文**：正文在 `40-kernels/softmax-normalization/03-normalization-fusion.md:53-345`（公式在 `:55-71`） |
| 想知道归约的访存账与融合形态 | **不在本文**：正文在 `40-kernels/softmax-normalization/03:213-263` 与 `40-kernels/elementwise-fusion` |
| 想知道两个算子**训练出来**哪个更好 | **本域给不出**（无 GPU、不训练模型）；论文自己的实验词是 `similarly or more effective`（**那是它的实验**，转述必须标明） |

> ★ **表 A 的数值判据**（计划 §3 Chunk 4）：① `eps = 0` 时两个算子都 `< 1e-14`；
> ② `eps` 三档偏差**严格递增**且 `1e-3` 档 `> 1e-5`；③ 平移：LayerNorm `< 1e-12`、RMSNorm `> 1.0`。
> 三条都在 `code/01_rmsnorm_layernorm.py` 的 `A.1`/`A.2`/`A.3`/`A.4` 里，
> 且**阈值本身被 `D.2` 逐位钉住**（放宽阈值 ⇒ 判据退化成恒真）。
