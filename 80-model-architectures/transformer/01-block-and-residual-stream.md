# 一个 block 的构成与残差流

> **一个 block 只有两件事：读残差流、写一个修正量；而残差流是唯一贯穿全部 L 层的那个张量。**
> 归一化放在残差**里面**还是**外面**，决定的不是「哪个更好」，而是**残差流的范数随深度涨还是不变**
> —— 后一种写法因此**必须**在末层补一个 `final_norm` 才接得上 `lm_head`。

## 0. 背景与动机

一个 L 层的模型，只有**一个**张量从头走到尾：宽度 `d`、长度是序列长的那条**残差流**
（HF 的命名是 `hidden_states`）。第 `l` 层做的是：

```
读它 → 算一个修正量 → 加回去
```

这两件事——「子层算修正量」与「加回去」——就是全部。**参数量全在子层里，残差本身没有一个参数**
（本域 `03-depth-and-width` 会给出这笔账的具体分布：Llama-3-8B 上 FFN 一项占 70.2%）。

「加回去」这一步（残差连接）带来的**结构**后果是可以精确写下来的：

| 没有残差 | 有残差 |
|---|---|
| `h_L = F_{L-1}(⋯F_1(F_0(x_0))⋯)` —— 深度方向是一串**复合** | `h_L = x_0 + Σ_l F_l(·)` —— 深度方向是一个**和** |

**「一个和」是可测的**：本域 `code/01_block_residual.py` 在本机跑了一条 24 层的玩具残差流
（`D=256`、`x_0 ~ N(0, 1)·0.5`、`W ~ N(0,1)/√D`、5 个种子），逐层范数从 `20.32` 长到 `254.57`，
而**逐层增量近似恒定**（首 5 项均值 `11.15` → 末 5 项均值 `9.90`，比值 `0.8878`）。

⚠ **但「不用残差会怎样」这件事，本域给不出结论。** 训练侧的账（梯度路径、退化）不在本域
（它的正文在 `normalization/02-placement-and-qk-norm`，此处回链）；本域只做**结构侧的账**——
而这些账不需要训练一个模型就能看见，这正是本域主线说的那件事。

## 1. 原理

### 1.1 两种写法的结构差别

记第 `l` 层的子层为 `F_l`，`LN` 表示归一化（**它的公式与误差模型的正文在
`40-kernels/softmax-normalization/03-normalization-fusion.md:55-71`**，正文在彼，此处回链；本文只关心它**放在哪**）：

```
post-LN（2017 原版）：  h_{l+1} = LN(h_l + F_l(h_l))
pre-LN （现代主流）：   h_{l+1} = h_l + F_l(LN(h_l))
```

两者的差别只有一处分组：**归一化是在「加法之后」还是「加法之前」**。但它决定了残差流范数的
**深度行为**——这是可以闭式写出来的。

### 1.2 推导一：pre-LN 的残差流是一个「同尺度求和」

把 pre-LN 的递推展开：

```
h_L = h_0 + Σ_{l=0}^{L-1} F_l(LN(h_l))          …… (1)
```

若每一项 `‖F_l(LN(h_l))‖` 的量级大致不变（子层与它的输入都被归一化「钉」在同一个尺度上），
那么 (1) 就是一个**等尺度求和**：正交假设下是随机游走的 `√L` 倍，同向假设下是线性的 `L` 倍。

本机实测（24 层）：末层/首层 = `254.57 / 20.32 = 12.53×`，而 `√24 = 4.90`、`24 = 24`
⇒ 实测值**介于两者之间、更靠近线性**，且逐层增量本身在缓慢下降
（首 5 项均值 `11.15` → 末 5 项均值 `9.90`，**降了 11.2%**）。

⇒ **正确的措辞是「近似线性增长」，不是「线性增长」，更不是「恒定」**。

### 1.3 推导二：post-LN 的范数恒为 √D（这是一条恒等式）

post-LN 每一层的末尾都归一化，而**归一化的输出**（eps → 0 时）逐 token 满足
均值 0、方差 1 —— 于是

```
‖h_l‖ = √(D · 1) = √D                                 …… (2)
```

与 `l` **无关**。本机实测（`D=256`，5 个种子）：末层范数 `15.999997359 / 15.999997277 /
15.999997305 / 15.999997296 / 15.999997327`，与 `√256 = 16` 的相对误差 **1.702e-07**。

★ **那 `1.702e-07` 是从哪来的？把 `eps` 设成 0 再跑一遍**：末层范数变成
`16.000000000000`（相对误差 `0.000e+00`，跨 5 个种子全部如此）。⇒ (2) 在 eps = 0 时是**恒等式**，
而 (1.3) 里那一点点偏差是 **eps 一项**造成的（`var/(var+eps)` 型的一阶偏差）。
**这条区分不是抠字眼**：它决定了这个量的「可断言强度」——见 §5 的判据表。

### 1.4 推导三：`final_norm` 的存在理由（一个可手算的闭式）

`lm_head` 是 `d → V` 的线性层，输出叫 logits：

```
logits = h_L · E ,   E ∈ R^{d×V}，本程序取 E ~ N(0, 1/d)
```

固定 `h_L`，看它在 `V` 个词上给出的那一行 logits：每一列是 `h_L · e_j`，而 `e_j` 的每个分量
`~ N(0, 1/d)` ⇒ `Var(h_L · e_j) = ‖h_L‖²/d` ⇒

```
std(logits) ≈ ‖h_L‖ / √d                                 …… (3)
```

而过了 `final_norm` 之后 `‖LN(h_L)‖ = √d`（式 (2)）⇒ `std(logits) ≈ √d/√d = 1`。于是

```
比值 = std(未归一化) / std(归一化后) ≈ ‖h_L‖ / √d          …… (4)
```

**本机实测**：`‖h_L‖ = 254.61`、未归一化 logits 的 std `15.9234`、归一化后 `1.0005`，
比值 `15.915×`；而闭式 (4) 给 `254.61/16 = 15.9134` —— 与实测的相对差 `0.0001`
（差的那一点点是 `V=32000` 的有限抽样噪声）。

⇒ **比值不是「某个 15.9 倍」，它就是 `‖h_L‖/√d`**：深度越深、`‖h_L‖` 越大，
**未归一化的 logits 尺度就越大**，也就是「输出头的数值条件与深度耦合」。
pre-LN 栈里 `final_norm` 就是用来切断这个耦合的（post-LN 栈**不需要**它：每层末尾已经在做同一件事）。

## 2. 执行映射

残差流是一个**活的张量**，不是每层各存一份的中间结果。这条结构事实有三个直接后果：

| 观察 | 后果 |
|---|---|
| L 层共享同一个形状 `(B, S, d)` 的缓冲区，每一层的子层**读它、写回它** | 参数量全部落在子层里；残差本身 0 参数。**「参数怎么分布」正是 `03-depth-and-width` 的账** |
| 每层只做一次「加法」——而加法是唯一被**每一层**都碰的操作 | 它是逐元素操作，与子层内部的矩阵乘在形态上完全不同（不重讲融合，正文在 `40-kernels/elementwise-fusion`，此处回链） |
| 末层的残差流**不经过任何归一化**就直接进 `lm_head` | 见 §1.4：logits 的尺度与深度耦合 ⇒ 现代栈在 `lm_head` 前补 `model.norm` |

**具体的模块名**（以 HuggingFace 的命名为例，本域不复核命名）：
`model.embed_tokens`（把 token 映到 `d`，写进残差流）、`model.layers[i].self_attn` /
`model.layers[i].mlp`（两个子层）、`model.norm`（即 `final_norm`）、`lm_head`（读放大后的残差流）。

**本机实测的量级**（`python3 3.13.5` + `numpy 2.4.4`，macOS arm64，**无 GPU**）：

| 量 | 值 | 口径 |
|---|---|---|
| `‖h_L‖ / ‖h_0‖` | **31.84×** | 分母 = 初始 `x_0`（`‖x_0‖ = 8.00`） |
| `‖h_L‖ / ‖h_1‖` | **12.53×** | 分母 = **第一层之后**（`‖h_1‖ = 20.32`） |
| 未归一化 logits 的 std | **15.9234** | `V=32000`、`N=64` |
| 过 `final_norm` 后的 std | **1.0005** | 同上 |

★ 前两行是**同一个量**（末层残差流涨了几倍），差 **2.54 倍**——分母是口径的一部分，
**报这个数必须写分母**（见 §4 的第 1 条）。

> ⚠ **本域没有 GPU**：上表是本机 `numpy` 上一条玩具残差流的推导值与实测值，
> **不是任何真实模型的测量**。它们支撑的是「范数的深度行为由归一化的位置决定」这条**结构**结论。

## 3. 实现与演进

| 阶段 | 写法 | 它换来了什么、付了什么账 |
|---|---|---|
| 2017 原版 | `LN(h + F(h))`（post-LN） | 每层末尾把范数钉在 `√D`（式 (2)）；代价：末层的输入尺度被压得很小，训练侧的账见 `normalization/02`（**本文不下训练侧结论**） |
| 现代主流 | `h + F(LN(h))`（pre-LN） | 残差流是一条**不衰减的通路**（式 (1)）；代价出现在**结构**里：范数随深度涨 ⇒ 末层**必须**补 `final_norm`（`03-depth-and-width` 的规格表里，`model.norm` 就是这一项） |
| 进一步 | 归一化本身的形态（LayerNorm → RMSNorm）、以及 QK-norm | **不在本文**，正文在 `normalization/01` / `normalization/02`（此处回链） |

**为什么 `final_norm` 只出现在 pre-LN 栈里**——这条可以用本域的两条判据直接判定：

- post-LN 栈：`‖h_L‖ = √D`（恒等式），`lm_head` 的输入尺度与深度**无关** ⇒ 不需要额外的 `final_norm`；
- pre-LN 栈：`‖h_L‖` 随深度涨（本机 24 层上 `12.53×`）⇒ 比值 `‖h_L‖/√d` 也跟着涨（本机 `15.915×`）
  ⇒ 需要一个 `final_norm` 把它拉回固定尺度。

### 落到真实结构上

`intermediate_size` / `head_dim` 这类字段的**逐字段标注**（哪个是 config 原生、哪个是推导）
在 `03-depth-and-width` 的规格表里（本文不重复）。这里只记一条与残差流宽度直接相关的结构事实：

**残差流的宽度是 `hidden_size`**；而 attention 那边**写回**残差流的宽度由 `o_proj` 的输入决定
——两者**不必相等**，真实模型里就有两者不相等的实例。
★ 那个实例的正文在 `45-kernel-lifecycle/requirement-discovery/01-model-to-operator-inventory.md:270-276`
（§4.5，判据在 `:288`）；本域**只在 `03-depth-and-width` 的规格表里做「逐字段标注」这一新增部分，
不重推那个例子**。

## 4. 踩坑与失败模式

**① 报「残差流涨了 N 倍」而不写分母。**

- **现象**：同一个模型、同一份代码，两次报告里分别是 `31.84×` 与 `12.53×`，读者以为换了个模型。
- **成因**：`x_0` 只是**初始化尺度**；从 `x_0` 到第一层之后的那一跳（`8.00 → 20.32`，2.5 倍）
  是**初始化**效应，不是深度效应。分母取 `‖x_0‖` 就把初始化效应混进了「深度的账」。
- **规避**：写「分母 = 第一层之后」（本域统一用这个口径）；要写另一个口径就**两个都写出来**。

**② 把「逐层增量恒定」当成恒定。**

- **现象**：判据①要求「逐层增量恒定」，于是有人断言 `增量 == 常数`，实际一跑就失败。
- **成因**：`增量` 是**近似**恒定的——本机首 5 项均值 `11.15` → 末 5 项均值 `9.90`（**−11.2%**）。
  ★ 更隐蔽的一层：**「用哪一个统计量」也有两个口径**。本域实测同一个量：
  首项→末项是 `12.32 → 9.89`（比值 `0.8026`），首/末 **5 项均值**是 `11.15 → 9.90`（比值 `0.8878`）。
  计划 §0.7-D 的 D10 记的 `12.32 → 9.89` 是**首项→末项**，而判据①写的口径是**首/末 5 项均值**
  —— 两者都能落进判定区间 `[0.7, 1.3]`，但**它们不是同一个统计量**（本域实施时已把这处口径不匹配
  记入报告）。程序把两个数都打印出来。
- **规避**：断言写成**区间**（本域用 `[0.7, 1.3]`）而不是等式；并且**在正文里写明用的是哪个统计量**。

**③ 「不加归一化就会发散」。**

- **现象**：把 pre-LN 的 `F(LN(h))` 写成 `F(h)`（去掉 LN），预期范数爆炸。
- **成因**：在本程序的设定下**不成立**——末层范数只从 `254.57` 涨到 `322.27`（**1.27 倍**），
  因为子层里的 `tanh` 把它的输出压在 `O(√D)` 上，增量的尺度**不随 `‖h‖` 增长**。
  ⇒ 这条断言的成立与否**取决于子层自身的形态**（非线性是否饱和），不是普适结论。
- **规避**：不要把它当通式写进正文；要写就写明**前提**（子层的输出幅度是否有界）。

**④ 末层忘了 `final_norm`。**

- **现象**：pre-LN 栈的末层残差流直接进 `lm_head`，logits 的尺度随深度增长（本机 24 层上
  未归一化 `15.9234` vs 归一化后 `1.0005`，相差 `15.915×`），且**逐 token 不同**。
- **成因**：见 §1.4 的闭式 `std(logits) ≈ ‖h_L‖/√d`——残差流越长，这个尺度越大。
- **规避**：pre-LN 栈必须在 `lm_head` 前补一个 `final_norm`；post-LN 栈不需要（每层末尾已经在归一化）。

**⑤ 把 post-LN 的 `‖h‖ = √D` 当成「模型学到的东西」。**

- **现象**：把它当成一个需要训练才出现的经验事实。
- **成因**：它是**恒等式**（式 (2)）——eps = 0 时本机实测相对误差 `0.000e+00`。
  实测里那 `1.702e-07` 的偏差**全部**来自 `eps`（把 eps 设 0 就精确到 16.000000000000）。
- **规避**：凡「恒等式」级别的结论，**断言写成机器精度档**（本域用 `< 1e-14`），
  不要写成 `== 0.0`（P18：两个互斥的要求不能写进同一条判据）。

## 5. 判据表

| 可机械判定的条件 | 结论 |
|---|---|
| 残差流的范数**跨层几乎不变**（相对极差 < 1e-6，跨种子极差 `8.23e-08` 同档） | 这是 **post-LN**：`‖h_l‖ = √D` 是**恒等式**（eps=0 时精确；本机 `16.000000000000`，相对误差 `< 1e-14`）。偏差那一项来自 `eps`（本机 `1.702e-07` < `1e-6`） |
| 残差流的范数**随深度增长**（本机 24 层、`D=256` 上 `12.53×`，分母取第一层之后） | 这是 **pre-LN**：末层**必须**有 `final_norm`，否则 `lm_head` 的输入尺度与深度耦合 |
| 逐层增量要断言「恒定」 | 只能断言**近似**恒定：本机首/末 5 项均值比 `0.8878`（−11.2%）∈ `[0.7, 1.3]`；★ 报这个比值**必须写明统计量**（首项→末项口径给 `0.8026`，是另一个数） |
| 报「残差流涨了几倍」 | 必须写**分母**：本机 `31.84×`（分母 `‖x_0‖`）vs `12.53×`（分母 `‖h_1‖`），差 2.54 倍 |
| `final_norm` 前后接 `lm_head` 的 logits std 之比 | 比值 **≈ `‖h_L‖/√d`**（可手算）：本机 `15.915×`（判据阈值 `> 10×`），闭式给 `15.9134`，相对差 `0.0001` < `0.02` |
| 想断言「不加归一化 ⇒ 发散」 | 在本域玩具设定下**不成立**（`254.57 → 322.27`，1.27×）；该断言取决于**子层输出是否有界**，不是普适结论 |
| 两条独立代码路径都给出同一条残差流 | 相对差必须在**机器精度档**（本域 `1.120e-16 < 1e-14`）；且参照实现**跑完后调用计数表必须为空**（本域 `A.3`：参照一次都没调用被测侧的函数） |
| 一个量出现「精确相等」 | 先分清是**恒等式**（如 eps=0 的 `‖h‖=√D`，断言用 `< 1e-14`）还是**构造出来的**（两边共用一份代码 ⇒ 差恒为 `0.0`，但它什么都证明不了，见 `00-meta/glossary.md:259`） |

> ★ **表 A 的阈值**（计划 §3 Chunk 1）：① 增量比值 ∈ `[0.7, 1.3]`；② post-LN 相对误差 `< 1e-6`；
> ③ logits std 之比 `> 10×`。三条都在 `code/01_block_residual.py` 的 `A.1` / `B.1` / `C.1` 里，
> 且阈值本身被 `D.4` 逐位钉住（放宽阈值 ⇒ 判据退化成恒真）。

## 6. 小结与延伸

**一句话**：残差流是唯一的贯穿通路，而**归一化放在加法前还是加法后**，决定的是
「残差流的范数随深度涨（pre-LN）还是不变（post-LN）」——前者的账**必须**在末层用 `final_norm` 结清。

- **本文的账是「数值条件的账」**：`pre-LN` 换来一条不衰减的通路，代价是末层的尺度与深度耦合；
  这笔账**不需要训练模型**就能算出来（§1.4 是一个可手算的闭式）。
- **训练侧的问题不在本文**：pre-LN 与 post-LN 的取舍（可去 warmup 等）正文在
  `normalization/02-placement-and-qk-norm`（正文在彼，此处回链）。★ 那里会写清一个措辞纪律：
  原论文的主张是 **`comparable`**，**不是**「pre-LN 更好」。
- **归一化的公式与误差模型不在本文**：正文在 `40-kernels/softmax-normalization/03-normalization-fusion.md:55-71`
  （正文在彼，此处回链）。本文只关心它**放在哪**。
- **残差流有多宽、参数怎么分布**：见 `03-depth-and-width`（同一主题的下一个编号）。
- **从 config 反算算子清单 / FLOPs / 参数量**：正文在
