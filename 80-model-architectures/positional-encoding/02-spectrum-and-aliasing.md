# θ_i 的谱、混叠周期、与分辨窗口

> 本文给**定量框架**：那条频率表 `θ_i = base^{-2(i-1)/d}` 到底长什么样、
> `base` 动得了它的哪一端、以及**为什么位置编码必然在两端的某一端出问题**。
> 三条结论：
> **`θ₁ = base⁰ = 1` 与 `base` 无关**（提高 `base` 只把低频端拉低，**动不了最高频那一维**）；
> **最高频分量的周期精确等于 `2π`** ⇒ 位置 `m` 与 `m+2π` 在它上面**不可区分**（判据 ④）；
> ★★ **一个闭式 `2·|sin(π·θ_i)|` 解释了「两端闭合、中间不闭合」，而且两端的原因相反** ——
> 高端是「正好一整圈」（`θ₁ = 1` 是**整数**），低端是「连一小段都没转完」（`θ·2π ≪ 1`）。
> ★ **本文不讲任何外推方法**（PI / NTK / YaRN 全在 [`03`](03-extrapolation.md)）——
> 计划 §3 的分工写死：**`02` 给定量框架、`03` 用它解释工程方法**。

## 0. 背景与动机

`01` 定下了 `θ_i = base^{-2(i-1)/d}`。这条式子看起来只是一个衰减到指数，
但它有两条**不对称**的后果，而这两条正是一整族工程方法（PI / NTK / YaRN）**存在的原因**：

- **高频端（`i` 小，`θ_i` 接近 1）**：转得**太快**。`θ₁ = 1` ⇒ 周期 `2π ≈ 6.28` 个位置
  ⇒ 在一个几千 token 的上下文里它已经转了上百圈 ⇒ **位置不可唯一确定（混叠）**。
- **低频端（`i` 大，`θ_i` 接近 0）**：转得**太慢**。`i = 32` 在 `S = 4096` 内只转 `0.087` 圈
  ⇒ **分辨不出相邻位置**（相位几乎没变）。

★ 本文要回答的是：**这两段分别从哪一维开始**、**它们能不能同时被满足**、
以及**「能分辨到多长」这个量怎么写成一个可手算的数**。

★ 那个数就是 `03` 要用的东西：本文定义的 **`turns_i(S) = θ_i·S / 2π`**（在长度 `S` 里转几圈）
与 YaRN 论文里的 `r = L/λ` **是同一个量**（`03` 的 `B.1` 把它做成恒等式）。

## 1. 原理

### 1.1 谱：一条几何阶梯，与 `base` 只动哪一端

`d` 维的 RoPE 有 `d/2` 条频率。实测（`d = 64`、`base = 10000`）：

| `i` | `θ_i` | `λ_i = 2π/θ_i`（位置） | `S = 4096` 里转几圈 |
|---|---|---|---|
| 1 | `1.00000000` | `6.283` | `651.90` |
| 2 | `0.74989421` | `8.379` | `488.86` |
| 3 | `0.56234133` | `11.173` | `366.59` |
| 4 | `0.42169650` | `14.900` | `274.90` |
| 8 | `0.13335214` | `47.117` | `86.93` |
| 16 | `0.01333521` | `471.172` | `8.69` |
| 32 | `0.00013335` | `47117.243` | `0.0869` |

`θ_i` **严格递减**、`λ_i` **严格递增**（逐差全过，不是抽样）⇒ 这是一条**几何阶梯**
（高频密、低频疏）。它同时是一张「波长表」：`λ` 从 `6.28` 个位置一直跨到 `47117` 个位置。

★★ **`θ₁ = base⁰ = 1` 是精确的，且与 `base` 无关**（判据 ③）。实测在三档上：

| `base` | `θ₁` | `θ₁` 的周期 | `θ_32`（最低频） | `λ_32` |
|---|---|---|---|---|
| `10000` | `1.0` | `6.283185` | `1.333521e-04` | `4.712e+04` |
| `500000`（Llama-3-8B） | `1.0` | `6.283185` | `3.013858e-06` | `2.085e+06` |
| `1000000`（Qwen3-30B-A3B） | `1.0` | `6.283185` | `1.539927e-06` | `4.080e+06` |

⇒ ★★ **提高 `base` 只把低频端拉低**（`λ_{d/2}` 从 `4.7e4` 拉到 `4.1e6` 个位置），
**最高频那一维一动不动**。★ 这是一对**两条**断言（`A.1` / `A.2`），不是一句概括。

★ 由此也能读出**两个真实模型 `rope_theta` 差 2 倍却都受同一个上限约束**的原因：
那个上限（`λ ≥ 2π` 那一端）由 `θ₁ = 1` 决定，而它与 `base` 无关。

### 1.2 混叠周期精确等于 `2π`（判据 ④）

因为 `θ₁` **精确等于 1**，第 1 对的周期**精确等于 `2π`**。
把它写成可判定的形式：**位置 `m` 与 `m + 2π` 在最高频分量上给出同一个分数**。

判据式（**尺度无关**）：`|s(m+2π) − s(m)| / (‖q_pair‖·‖k_pair‖) < 1e-12`，
其中 `s(m)` 是第 1 对在相对位置 `m` 上对 `⟨q,k⟩` 的贡献。

实测（`d = 64`、`θ₁ = 1`、尺度 `‖q_pair‖·‖k_pair‖ = 4.420649`）：

| `m` | `s(m)` | `s(m+2π)` | 差/尺度（**判据**） | 差/\|s\|（D4 的口径） |
|---|---|---|---|---|
| `10.0` | `4.0343611753` | `4.0343611753` | `0.0000e+00` | `0.0000e+00` |
| `50.0` | `-4.0372581195` | `-4.0372581195` | `2.0092e-16` | `2.2000e-16` |
| `200.0` | `-1.5357446189` | `-1.5357446189` | `6.4293e-15` | `1.8507e-14` |
| `1000.0` | `-3.0175757116` | `-3.0175757116` | `1.5571e-14` | `2.2811e-14` |

★ 与计划 §0.7-D 的 **D4** 记录（`0.000e+00 / 2.2e-16 / 1.85e-14 / 2.28e-14`）**逐位一致** ——
那是**右列**（`差/|s|`）的口径。本文的判据用**左列**（尺度无关），并把右列一起印出来。

★★ **判据④ 不是恒真断言**（`C.1`）：把位移从**一整圈**（`2π`）换成**半圈**（`π`）⇒
同一个量从 `1.56e-14` 掉到 `1.8265` ⇒ 「不可区分」**专指 `2π` 这一位移**，
不是「高频分量对位移不敏感」。

### 1.3 分辨窗口：`turns` 这个量

定义（★ 这是本域与 `03` **共用的那个式子**）：

```text
turns_i(S) := θ_i · S / 2π          「在长度 S 的上下文里，第 i 维转了几圈」
```

★ 它有三个名字，指的是**同一个量**：
**本文的 `turns`** ≡ **YaRN 论文的 `r = L/λ`**（`03` 的 `B.1` 把它做成恒等式）
≡ **`θ_i·S` 的弧度数除以 `2π`**（计划 §0.7-D 的 **D6** 记的是**弧度版**）。

实测（与 D6 同口径：`d = 64`、`base = 10000`）：

| | `θ_i·S`（弧度） | `turns`（圈） |
|---|---|---|
| `i = 1`，`S = 128` | `128.0000` | `20.3718` |
| `i = 32`，`S = 4096` | `0.5462` | `0.0869` |

★ 与 D6 的「`128 rad`」与「`0.546 rad`」**逐位一致**（同口径、同 `d`、同 `base`）。

⇒ ★ **两端是两种不同的失败**：`i = 1` 在 `S = 128` 内就转了 **20 圈**（早就混叠）；
`i = 32` 在 `S = 4096` 内只转 **0.087 圈**（连一小段都没转完，分辨不出）。

### 1.4 ★★ 闭式：一个式子解释三个频段

把第 `i` 对的贡献写成 `c_i(δ) = R_i·cos(δθ_i − φ_i)`（`R_i = √(A²+B²)`，`A`、`B` 由该对的两个分量给出）。则

```text
max_δ |c_i(δ + 2π) − c_i(δ)|  ==  2·|sin(π·θ_i)|·R_i          （恒等）
```

（推导只有两步：`c(δ+2π) − c(δ) = −2·sin(πθ)·R·sin(δθ − φ + πθ)` ⇒ 逐点 `≤ 2|sin(πθ)|R`，
等号在 `δ* = (φ − πθ + π/2)/θ` 处取到。程序里那个 `δ*` 是**解析给出的**，不是搜出来的。）

实测（`d = 64`、`θ` 见下表、`δ*` 由闭式给出）：

| `i` | 实测 `max\|Δ\|` | 闭式 | 相对差 |
|---|---|---|---|
| 1 | `8.881784e-16` | `1.082747e-15` | ★ 两边都在机器精度档 |
| 2 | `1.086325e+00` | `1.086325e+00` | `2.04e-16` |
| 3 | `1.600957e+00` | `1.600957e+00` | `0.00e+00` |
| 4 | `4.982129e+00` | `4.982129e+00` | `0.00e+00` |
| 8 | `7.448896e-01` | `7.448896e-01` | `0.00e+00` |
| 16 | `5.144317e-02` | `5.144317e-02` | `1.89e-15` |
| 32 | `5.301029e-04` | `5.301029e-04` | `1.83e-13` |

⇒ ★★ **一个式子解释三个频段**：

| 频段 | `2·\|sin(πθ_i)\|`（纯闭式，与样本无关） | 为什么 |
|---|---|---|
| `i = 1`（`θ = 1`，**整数**） | `2.45e-16` | **`sin(π·1) = 0`** ⇒ 位移**正好是一整圈** ⇒ **精确闭合** |
| `i = 2, 3, 4, 8` | `1.4147 / 1.9618 / 1.9398 / 0.8136` | `θ` 在 `(0,1)` 中间 ⇒ `O(1)` ⇒ **不闭合** |
| `i = 32` | `8.3788e-04` | `θ·2π ≪ 1` ⇒ **位移只是它周期的一小段** ⇒ 近似闭合 |

★★ **两端「都闭合」，但原因相反** —— 这正是计划 §3 表 A ⑤ 要的那句话，
而闭式把它的**机制**写清楚了：高端是**整数**（`θ₁ = 1`，一整圈），
低端是**小量**（`2πθ ≪ 1`）。★ 本谱里唯一使 `sin(πθ) = 0` 的维**只有 `i = 1`** ——
因为 `θ_i = base^{-2(i-1)/d}` 只有 `i = 1` 是指数 `0`。

### 1.5 ★★ 两端互斥：一条不等式，不是一次测量

现在把 `§1.1` 的两段失败写成两条**条件**：

```text
「相邻位置可分」：  θ_i ≥ 1.0            （每走一个位置，相位至少变 1 rad）
「整窗不混叠」  ：  turns_i(L) ≤ 1.0     （整段上下文里最多转 1 圈）
```

★★ **这两条对任何 `L > 2π` 都不可能同时成立**：
第二条等价于 `θ_i ≤ 2π/L`，而 `2π/L < 1` ⇒ 两个区间 `[1, 2π/L]` 与 `[2π/L, 1]`
**方向相反** ⇒ **交集为空**。

**⇒ 形状上的结论**：任何单一频率**都不可能在整段上下文里既分辨相邻位置又不混叠**
（除非 `L ≤ 2π ≈ 6.28` 个位置）。这就是「位置编码**必须**是一条谱」的**原因**，
也解释了为什么**谱的两端必然分别落进两个失败模式**。

实测（`d = 128` = 两个真实模型的 rotary 维数；两条阈值的交集）：

| 模型 | `base` | `L` | `θ_i ≥ 1` | `turns_i(L) ≤ 1` | **交集** |
|---|---|---|---|---|---|
| Llama-3-8B | `500000` | `8192` | `1` 维 | `29` 维 | **`0`** |
| Qwen3-30B-A3B | `1000000` | `40960` | `1` 维 | `23` 维 | **`0`** |

★ 把第一条阈值从 `1.0` 放宽到 `0.1` / `0.01`，交集**仍然是 `0`**（六个格子全过）
⇒ 结论**不挑阈值**（`C.2`）。★ `2π/L` 在这两个模型上是 `7.670e-04` / `1.534e-04`（都 ≪ 1）。

## 2. 位置容量的账（★ 不是访存账）

「位置编码能编多长」这个问题，在本文的框架里可以拆成**三个数**，各自可手算：

| 数 | 定义 | 它回答 |
|---|---|---|
| `λ_i = 2π/θ_i` | 第 `i` 维的**波长** | 这一维多久重复一次 |
| `turns_i(S) = θ_i·S/2π` | 在长度 `S` 里转几圈 | 这一维在 `S` 内**是否够用** |
| `θ_i` | 每位置相位 | 这一维**能否分辨相邻位置** |

★ 而**`d/2` 条频率一共给出多少个「位置刻度」**这件事**不由 `d/2` 决定**，
而由**最长的那条波长**决定：`λ_{d/2}` 是 `4.7e4`（`base = 1e4`）到 `4.1e6`（`base = 1e6`）个位置。
⇒ ★ **`base` 是「位置容量」的旋钮**，而它的上限出现在另一端（`§1.1`）。

★ **本文不算**位置编码的 FLOPs / 访存账（正文在 `40-kernels/attention`），
也不算 `λ_i ≥ L` 的那些维**具体该怎么处理** —— 那是 `03`。

## 3. 实现与演进

**两个真实模型的谱里，哪些维「整窗连一圈都没转完」**（即 `λ_i ≥ L`，`d = 128`）：

| 模型 | `base` | `L` | `λ_i ≥ L` 的维 | 维数 | 占比 |
|---|---|---|---|---|---|
| Llama-3-8B | `500000` | `8192` | `i = 36 … 64` | `29` | `45.3%` |
| Qwen3-30B-A3B | `1000000` | `40960` | `i = 42 … 64` | `23` | `35.9%` |

★ **这两个数就是 `02` 交给 `03` 的输入**：它们正是 YaRN 的 `L/λ_i` 判据里
「`λ` 等于或大于上下文长度 ⇒ 只插值」那一类维（`03` 的 `B.1` 把两边的**集合**做成等式）。
★ **本文到此为止** —— 那些维**怎么办**（插值 / 换 base / ramp）是 `03` 的正文。

★★ **口径提醒**：上表的 `d = 128` 是**两个真实模型的 rotary 维数**；
而 `§1.1`–`§1.4` 的谱表用的是 `d = 64`，那是**探测脚本的口径**
（计划 §0.7-D 的 D3–D6 全出自它）⇒ 两组数**不能混着比**。
程序把这两个 `d` 写成**两个具名常量**（`D_SPEC` / `D_MODEL`）并各自钉住 ——
实测用错会**静默**换掉结论：Qwen3 的「整窗不混叠」维数在 `d = 64` 时是 **11**、
在 `d = 128` 时是 **23**，**差一倍**。

**来源等级**：`rope_theta` 与 `max_position_embeddings` 来自两份 `config.json`
（**经 `hf-mirror.com` 镜像取得，未与官方 repo 比对 sha256** ——
这条限定语必须与数字一起写）。★ rotary 维数 `128` 有**两种等级**：Qwen3 的 `head_dim`
是 **config 原生字段**（而 `128 ≠ 2048/32`），Llama 的 config 里**没有该字段**、
它的 `128` 是 **[E] 推导**（本域引自 `transformer/code/specs.py`）⇒ 数值相同、**引用时必须分开标注**。

## 4. 踩坑与失败模式

### 4.1 用相对极差量一个机器精度档的量

- **现象**：`(max−min)/|mean|` 给出一个「看起来不成立」的数。
- **成因**：分子恒在机器精度档（`~1e-13`），分母由数据决定 ⇒ 比值的上界不存在。
- **规避**：尺度无关的绝对判据（`01` 的 `C.1` 把这件事量成了 4433 倍的差）。

### 4.2 ★★ 把 `max` 与 `mean` 混在一个统计量里（本程序实测的**新**形态）

计划 §3 表 A ⑤ 给的判据式是

```text
err_i = max_n |c_i(δ+2π) − c_i(δ)| / mean_n |c_i|
```

★ **它的分子取样本上的 `max`、分母取样本上的 `mean`** ⇒ 它**不是**「相对误差」。
实测：把它与 `§1.4` 的闭式相除，

| `i` | 2 | 3 | 4 | 8 | 16 | 32 |
|---|---|---|---|---|---|---|
| `err_i / 闭式` | `3.20` | `3.65` | `4.13` | `5.48` | `4.23` | `3.28` |
| 样本振幅离散度 `max_n R_n / mean_n R_n` | `4.09` | `3.71` | `4.29` | `4.75` | `4.68` | `4.04` |
| 两者之比 | `0.78` | `0.98` | `0.96` | `1.15` | `0.90` | `0.81` |

★★ **两行的比值落在 `[0.78, 1.15]`** ⇒ **那个放大因子就是样本振幅离散度**
（外带一个固定的 `δ0` 相位因子）。机制可以一句话说清：
`2·|sin(πθ_i)|` 在分子分母里**都出现、被约掉** ⇒ 这个因子**与 `θ` 无关**
（实测 `θ` 从 `i = 2` 到 `i = 32` 跨 `4217` 倍，而因子只动 `1.71` 倍）。
★ 处置：**两个口径都写出来、各自都断言**（`B.2` 按计划的原式、`B.4` 用闭式、
`B.4b` 把这条注记本身做成**三条不等式**）。★ 这是计划 §0.1 第一类错误
（**判据的统计量不稳**）的又一现场。

### 4.3 把「几个读数」写成「一个范围」

- **现象**：把 `i = 1, 2, 3, 4, 8, 32` 六个读数写成「`i = 2..8` 是 `7.80/11.01/11.87/6.16`」
  —— **四个数对不上一个范围**（`2..8` 里还有 `5/6/7`）。
- **成因**：闭式 `2|sin(πθ_i)|` 是**连续**下降的，两端的阈值之间**必然**有一段**过渡带**。
- **规避**：把「闭合」「不闭合」两组**逐个列出**（`CLOSING_INDEX` / `NONCLOSING_INDEX`），
  并把过渡带那一个（`i = 16`，`err = 0.5808`）**明确排除在断言之外**（`B.3`）。
  ★ 这不是「异常」，是**中间态**。

### 4.4 把两个 `d` 混着用

- **现象**：`§1.1` 的谱表是 `d = 64`，而 `§1.5`/`§3` 的计数是关于真实模型的 `d = 128`。
- **成因**：两组数**都叫 `θ_i`、都叫「维数」**，但口径不同。
- **规避**：两个 `d` 写成**两个具名常量**并各自钉住；正文里每次出现都写出口径
  （★ 这是本库的「量法口径」纪律，`01` 的 `§4.2` 是它的另一种现场）。

## 5. 判据表

| 可机械判定的条件 | 结论 |
|---|---|
| `θ₁` 在 `base ∈ {1e4, 5e5, 1e6}` 上的取值 | **精确 `== 1.0`**（`base⁰`）⇒ 与 `base` 无关 |
| `θ_{d/2}` 随 `base` | **严格下降**（`1.334e-04 → 3.014e-06 → 1.540e-06`）⇒ 提高 `base` **只动低频端** |
| `θ_i` 的单调性 / `λ_i` 的单调性 | 严格递减 / 严格递增 ⇒ 谱是一条**几何阶梯** |
| 位置 `m` 与 `m+2π` 在**最高频分量**上的分数 | 差/尺度 `< 1e-12`（实测 `0 / 2.0e-16 / 6.4e-15 / 1.6e-14`）⇒ **不可区分**；★ 换成半圈 `π` ⇒ `1.83` ⇒ 判据**不是**恒真的 |
| `max_δ\|c_i(δ+2π) − c_i(δ)\|` | **恒等于** `2·\|sin(πθ_i)\|·R_i`（`i ≥ 2` 相对差 `< 1e-12`）⇒ `θ` 为**整数**时精确闭合、`θ·2π ≪ 1` 时近似闭合、中间不闭合 |
| 计划 §3 表 A ⑤ 的 `err_i` | `err_1 = 0.0000`、`err_32 = 0.0043`（`< 0.01`）；`err_i > 1.0` 对 `i ∈ {2,3,4,8}`（`7.80 / 11.01 / 11.87 / 6.16`）；★ `i = 16` 在**过渡带**（`0.5808`），**不断言** |
| 同一个 `err_i` 与闭式相除 | 恒 `> 1` 且跨 `1.71` 倍（`3.20 ~ 5.48`）⇒ **分子 max / 分母 mean 是口径混用**，不是 `θ` 的性质 |
| 「相邻位置可分」（`θ_i ≥ 1`）与「整窗不混叠」（`turns_i(L) ≤ 1`） | 对任何 `L > 2π` **交集为空**（`2π/L < 1`）⇒ **单一频率不可能两者兼得**；两个真实模型上实测交集都是 `0`，且对三个阈值都成立 |
| 想知 `L/λ_i` 是什么 | 就是本文的 **`turns_i(L)`**（`03` 的 `B.1` 把两边做成恒等式）⇒ `02` 与 `03` 之间**唯一的那座桥** |
| 想知道 `λ_i ≥ L` 的那些维**怎么办** | **不在本文**：插值 / 换 base / ramp 全在 [`03`](03-extrapolation.md) |
| 想知道位置编码的 FLOPs / 访存账 | **不在本文**：`40-kernels/attention` |

## 6. 小结与延伸

**一句话**：这一篇的账是**位置容量的账** ——
`θ_i` 是一条从 `1` 衰减到 `base^{-(d-2)/d}` 的几何阶梯；
**两端各有一种失败**（高端混叠、低端分辨不出），且**两者不可能同时避免**；
`base` 只能动低端那一半。

  PI / NTK-aware / NTK-by-parts / YaRN / ALiBi，**用本文的 `turns` 统一解释**。
  ★ 那座桥是 `turns_i(L) ≡ r_i = L/λ_i`（`03` 的 `B.1`）。
- **相关的架构问题**：`attention-variants/03-window-and-hybrid` 讲的是**另一种**扩展上下文的方式
