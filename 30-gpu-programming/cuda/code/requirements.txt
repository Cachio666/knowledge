# ── numpy 在本主题里干什么（不是装饰，三个程序都在用）──────────────────────
#   · 01_sync_contract.py  §B 的代价模型用 **int64 数组**：
#       - `np.array([...], dtype=np.int64)` 统计 7 个文件里那行表达式的出现次数
#         （`occ_arr.sum() == 7`、`(occ_arr == 1).all()`）；
#       - 超发倍率用 int64/int64 的 float64 除法复核。
#       ★ 选 int64 不是随便挑的：**numpy 的整型除法 `//` 与 C 一样是截断除法**，
#         与 01 自己实现的 `_ev`（C 语义求值器）同口径。用 `int(a/b)` 会在
#         |a/b| > 2**53 时丢精度 —— 这正是 01 的 A.2 那条断言钉住的点。
#   · 02_stream_dag.py     A.5b 用 **bool 矩阵的幂**独立求传递闭包：
#       `R = R | (R @ R)` —— numpy 在 bool dtype 上的 `@` 就是**布尔半环**
#       （乘 = 与、加 = 或）。它与集合式的 `reachability()`（邻接表上的不动点迭代）
#       是两条不同的算法，两者必须给出同一个可达关系。
#   · 03_graph_capture.py  变体表用 `int8` 码表（合法 = 1 / 失效 = -1）**逐格**比对；
#       省下的宿主动作数用 int64 数组差算。
#
