# 30-gpu-programming/triton 的第三方依赖
#
# ★ 只有一个：**numpy**。启用方式：`python3 -m pip install -r requirements.txt`
#
# ── numpy 在本主题里干什么（不是装饰，四个程序都在用）────────────────────────
#   · minitriton.py（引擎）  块内张量就是 numpy 数组；**属主映射** `Layout.owners()`
#       是逐元素的 int64 数组（`spt×tpw×wpc` 的坐标分解全部用 numpy 向量化）；
#       三相归约的**真跑模拟**用 numpy 的 `reshape/sum/take` 表达「线程内 / 蝶形 / 跨 warp」；
#       `np.array_equal(owners_a, owners_b)` 是「这次转换免不免费」的**唯一**判据。
#   · 01_block_model.py      masked load/vadd 的逐元素结果、32000 个 softmax 输出、
#       NaN 计数（`np.isnan`）、毒区检查（`poison_tail`）—— 全是 numpy 的数组口径。
#       ★ 毒值 `POISON = np.float32(1.0e30)`：它必须**是一个 f32 能表示的数**，
#         否则「毒值没被改动」这条断言就落不到同一个数上。
#   · 02_masking.py          「五种掩码写法 × 5120 个位置」的逐位比对、
#       `np.clip` 的**第二条独立参照**（`refs.masked_index_np_ref`）、
#       60 个 (N, BLOCK) 组合的扫掠。
#   · 03_layout.py           128×128 的 tile、`L.owners()` 的属主分布统计、
#       两张图的**逐位相同**判据（`np.array_equal`）。
#   · 04_warp_reduce.py      蝶形 XOR 伙伴合并（`np.arange(tpw) ^ (1 << k)`）、
#       用一块 numpy 数组当**共享内存**并数 barrier。
#
# ── 本主题**明确不需要**的东西（写出来是为了让「没装」不等于「忘了写」）────────
#   · **不需要 triton** —— `triton` 包在本机**全机器不存在**（macOS 无 wheel，逐个解释器
#     核实过）。本目录跑的是**本仓库的迷你实现**；关于真实 Triton 的一切结论
#     只出现在 `specs.py` 的**逐字引文**里，且**不作为程序断言**（那会是自证）。
#   · **不需要 torch / numba / cuda-python** —— 一个都不 import。
#     `make lint` 用 `ast` 对这条做**机械检查**（含 `specs.py`，含 `import_module`
#     这类动态导入）；注释与 docstring 里出现这些词不算违规。
#   · **不需要 GPU、不需要 CUDA 工具链** —— 本机是 Apple M1 Pro，无 GPU、
#     无 nvcc / cuobjdump / nvdisasm / ptxas / ncu。**本目录不写 `.cu`**。
#   · **不需要网络** —— 只有 `make anchors` 这个**可选**目标需要（它从官方文档
#     再抽取词频与 7 条锚点，按 `specs.py` 写明的口径）。`make run` 完全离线。
#
# ── ★ 本主题的「真值」是什么（与 cuda / cutlass 两主题的区别）────────────────
#   `cuda` 与 `cutlass` 依赖**外部源码树**（训练系列、CUTLASS、pycute）。
#   **本主题不依赖任何外部源码树**：它的真值是
#     ① 官方文档的**逐字引文**（`specs.py` 的 7 条 A 级锚点，可 `make anchors` 复算）；
#     ② `refs.py` 的**独立参照**（纯 Python 标量 + math，**不 import minitriton**）——
#        它与解释器、numpy 构成**三条互不重叠的代码路径**，A 类断言的全部意义在此；
#     ③ **元检验**（`meta_falsify.py`）：往引擎里注入 D1–D5，**断言编号程序必须失败**——
#        这是对 P12（「模拟器同时是被测对象」）的**正面回答**，不是一句小心。
#
