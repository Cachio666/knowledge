# 量化误差界：Δ/2、Δ²/12 与 6.02n + 1.76 的前提

> 把连续的 `x` 压到步长 Δ 的格点上，误差绝对值**精确**不超过 Δ/2（前提是不越界），误差方差**近似**等于 Δ²/12；而流传最广的 `SQNR = 6.02n + 1.76 dB` **只在满量程正弦下成立**——它的一般形式有两个各自自洽的口径，混着用会偏高 6 dB。

## 0. 背景与动机

拿一个具体的对照：把同一个 8 位量化器用在两种张量上——一张是 GPT-2 的权重，一张是某个 ReLU 之后的激活。两者都是 `float32`、都用 min-max 对称量化、都是 8 位。测出来的 SQNR 会差 **15 dB 以上**（本机实测：`N(0,1)` 38.90 dB vs 单边指数 32.82 dB，而 `U(-1,1)` 能到 48.09 dB，判据见 §5）。同一个比特数，同一个量化器，结果差这么多——**因为「8 位能买到多少 dB」不是量化器的属性，是「量化器 + 输入分布」的属性**。

这篇文章要做的是把这件事讲成可算的账，而不是「反正低位宽就崩」。具体回答四个问题：

1. 误差**最坏**能有多大？（Δ/2 界——这是个精确的界，不是估计）
2. 误差**平均**有多大？（Δ²/12——这是个近似，附四条容易不成立的假设）
3. `6.02 dB/bit` 这条斜率从哪来、常数项 `1.76` 从哪来？
4. 这条公式什么时候不能用？

**不用正确的界的代价是具体的**：以为 8 位一定有 49.92 dB，于是把激活和权重按同一个规格设计，然后在激活那一侧掉 11 dB 而找不到原因（本机实测：`N(0,1)` 在 8 位对称下只有 38.90 dB，离 49.92 差 11.0 dB）。

本文只讨论**均匀标量量化**（定点那一支）。浮点格式的量化误差是另一条线：`03-bf16-fp16-tf32` 已经给出「浮点 SQNR 与分布几乎无关」的实测（跨四个分布 1.02 dB），本文 §1 第六步会用它作对照——**两条结论不冲突，因为它们说的是两种不同的量化器**。

## 1. 原理

### 第一步：Δ/2 界是精确的

设量化器把实数轴切成间距 Δ 的格点，输出**最近**的格点：

```
x̂ = round(x / Δ) · Δ
```

误差 `e ≜ x̂ − x`（**量化后减量化前**，Oppenheim & Schafer 的约定）。对任何落在量化器覆盖范围内的 `x`，它到最近格点的距离 ≤ 相邻格点间距的一半，所以

```
−Δ/2 ≤ e ≤ Δ/2
```

**这个不等号是精确的，不是近似**——它只用到了「最近」这个词。本机实测（`code/05_error_bounds.py` §A1，2×10⁶ 样本）：`max|e| / (Δ/2)` 在 `U(-1,1)` 与 `N(0,1)` 上、4 位与 8 位上，**两个格子是 `1.000000`、另外两个是 `0.999999`**——差异全在 float64 的表示误差以内（判据见 §5 表 1）。

⚠ 符号约定要写死：若改用 `e ≜ x − x̂`，不等号的**方向不变**，但后面第三步「截断恒为负」会翻成「恒为正」。**同一篇文章里只能用一种约定。**

### 第二步：σ² = Δ²/12 是四条假设换来的

把误差当成随机变量。假设（教科书原文列举的四条）：

1. `e` 是平稳过程；
2. `e` 与 `x` 不相关；
3. 误差样本之间互不相关；
4. `e` 在 `[−Δ/2, Δ/2]` 上**均匀**分布。

第 4 条一旦成立，方差就是一段均匀分布的方差：

```
σ_e² = (1/Δ) ∫_{−Δ/2}^{Δ/2} e² de = (1/Δ)·[e³/3]_{−Δ/2}^{Δ/2}
     = (1/Δ)·(2/3)·(Δ/2)³ = Δ² / 12
```

本机蒙特卡洛验证（同一批 2×10⁶ 样本，判据：**样本范围就是量化器范围，即无过载**）：`Var(e)/(Δ²/12)` 落在 **0.9998 – 1.0004** 之间（四个格子）。偏离 1 的部分是有限样本的统计抖动，不是偏差。

**这四条假设很容易不成立**，教科书自己就声明了它只在「步长小、信号复杂、未过载」时是好近似。本文 §4.4 给出三个真的跑出来的反例：输入恒等于 0.2 时比值是 **0.0000**；输入均匀落在 `[0, 0.1]`（远小于一个步长）时是 **0.1597**；相干采样的正弦是 **0.9172**。**看 Δ²/12 之前先问「我的信号满足那四条吗」。**

### 第三步：截断的误差是舍入的两倍

硬件里不一定有「最近舍入」。两级补码截尾（丢掉低位）等价于朝 −∞ 取整：

```
x̂_trunc = floor(x / Δ) · Δ
```

在同一个 `e ≜ x̂ − x` 约定下，`x̂_trunc ≤ x̂_round`，于是

```
−Δ < e ≤ 0        （**恒为负**，上界是舍入的两倍）
```

本机实测（§A3，2×10⁶ 样本，Δ = 2/256）：

| | 实测区间 | 峰值 | RMS |
|---|---|---|---|
| 最近舍入 | `[−0.00390624962, +0.00390624459]` | Δ/2 | Δ/√12 |
| 截断 | `[−0.00781249913, −5.29e−09]` | **Δ** | Δ/√3 |

截断 RMS / 舍入 RMS = **2.001**。「误差是两倍」指的是**幅度**（峰值和 RMS 都是 2 倍）；**方差是 4 倍**。这两个说法经常被混着用，写文档时必须说明是哪一个。

换一个常见但错误的说法：「截断有半个步长的偏置」。偏置是 Δ/2（均值），峰值是 Δ——**偏置和峰值不是同一个量**，与另一篇文章里的数字并列时尤其危险（§4.5）。

### 第四步：6.02n + 1.76 的两个常数从哪来

满量程正弦、理想 B 位量化器、量化噪声在 `[−Δ/2, Δ/2]` 均匀、测到 Nyquist 带——在这个设定下：

```
Δ = 满量程跨度 / 2^B
σ_e² = Δ²/12
满量程正弦的功率 = (峰值)²/2 = (跨度/2)²/2 = 跨度²/8

SNR = 10·log10(σ_x²/σ_e²) = 10·log10( (跨度²/8) / (跨度²/2^{2B} / 12) )
    = 10·log10(12·2^{2B}/8) = 10·log10(12/8) + 20B·log10(2)
    = 1.7609 + 6.0206·B
```

即 `6.02B + 1.76`。**两个常数只来自两处**：`6.02 = 20·log10(2)`、`1.76 = 10·log10(12) − 20·log10(2) = 10.79 − 6.02`。注意 `10.79 = 10·log10(12)` 这个数**在一般式里会原样出现**——这就是下面两条口径的公共来源。

**去掉「满量程正弦」这个前提，就有两种各自自洽的写法**，区别只在 `Xm` 指什么：

| 口径 | `Xm` 的含义 | 一般式 | 退化条件 | B=8 的退化值 |
|---|---|---|---|---|
| **A（跨度）** | 满量程跨度（peak-to-peak） | `SNR = 6.02B + 10.8 − 20log10(Xm/σx)` | `σx = Xm/(2√2)` | **49.929 dB** |
| **B（峰值）** | 峰值幅度（peak） | `SNR = 6.02B + 4.77 − 20log10(Xm/σx)` | `σx = Xm/√2` | **49.920 dB** |

两个常数只差 `20·log10(2) = 6.02 dB`，而两个退化条件也恰好差 `√2` 的比值——**这正是它们能互相抵消、两条路都落到 1.76 的原因**。

**判据（这是本文最重要的一条检查）**：两种口径**都必须能退化到 `6.02B + 1.76`**。对不上，就是拼错了。本机验证（§A5）：A 口径 49.929、B 口径 49.920，两者与 `6.02·8 + 1.76 = 49.920` 的差都 < 0.02 dB。

### 第五步：满量程正弦的实测

用真 torch 跑本文的定义（判据必须一起写，否则复现不出）：

- `x_k = sin(2π·frac(k·φ))`，`φ = (√5−1)/2`——**无理相位**，避免采样点与格点共振
- **mid-tread**：`x̂ = round(x/step)·step`，`step = 满量程跨度 / 2^B = 2/2^B`，N = 10⁵

| B | 实测 | 公式 `6.02B+1.76` | 差 |
|---|---|---|---|
| 8 | **50.017 dB** | 49.92 | +0.10 |
| 16 | **98.087 dB** | 98.08 | +0.01 |

实测**略高于**公式。成因已定位：正弦的幅度分布不是均匀的，实测误差方差 / (Δ²/12) = **0.9790**（§A4，10⁶ 样本）。**这不是测量误差，是 Δ²/12 那条「误差均匀」假设在正弦上不精确。**

⚠ **这个实测值依赖量化定义**。同一批样本换定义（§5 表 3）：对称 `/127` 给 **49.949**、mid-rise 给 **49.788**、对称 `/127.5` 给 **49.753**、截断给 **43.867**——**都到不了 50.02**。

### 第六步：定点 vs 浮点——同一个问题，两套答案

到这里必须停下来分清一件事：**上面整段讲的都是定点。**

`6.02n + 1.76` 的一般式里，`20log10(Xm/σx)` 这一项**把信号分布直接写进了公式**。也就是说**定点的 SQNR 强依赖分布**。本机实测（8 位对称、N = 2×10⁶，四个分布）：

| 分布 | `N(0,1)` | `U(-1,1)` | `Laplace(0,1)` | 单边指数 |
|---|---|---|---|---|
| 定点 8-bit 对称 | 38.90 | 48.09 | 32.57 | 32.82 |
| **跨分布极差** | | | | **15.52 dB** |

**浮点不是这样。** 把同一批样本直接 cast 到 bf16 / fp16 / e4m3fn：

| 格式 | `N(0,1)` | `U(-1,1)` | `Laplace(0,1)` | 单边指数 | 跨分布极差 |
|---|---|---|---|---|---|
| `bfloat16` | 55.59 | 56.61 | 55.61 | 55.60 | **1.02 dB** |
| `float16` | 73.65 | 74.68 | 73.67 | 73.66 | **1.02 dB** |
| `float8_e4m3fn` | 31.52 | 32.54 | 31.55 | 31.53 | **1.02 dB** |

**定点 15.52 dB vs 浮点 1.02 dB —— 差 15 倍。** 这就是为什么「`6.02n+1.76` 适不适用于 LLM」这个问题**必须先问是定点还是浮点**：浮点格式把动态范围做进了格式本身，不需要 `clipping`，它的误差是**相对**误差；定点格式的动态范围由 `Xm`（量程）决定，量程选大了所有人一起损失分辨率（本文 §1 开头的那个 15 dB 就是这件事）。

> ⚠ **不要写「浮点的跨分布波动小于 1 dB」**：本机实测三个格式都是 **1.02 dB**。而这个量就跨在 1 dB 上——同一段代码用标准库 `random` 在 2×10⁵ 样本上量到 **0.997 dB**（`verify_theory.py` §A5），用 torch 在 2×10⁶ 样本上量到 **1.02 dB**。**两端点自己就把「< 1 dB」这句否证了。** 正确的写法是给端点 + 说明分布集。

## 2. 执行映射

**这个界在真实系统里活在三个地方。**

**（1）observer 的 amax 决定 Δ，Δ 决定一切。** `torch.ao.quantization` 的 `MinMaxObserver` 扫一遍校准数据取 `amax`，然后 `scale = amax / QMAX`。也就是说 `Δ = 2·amax / (2^B)`——**界的宽度完全由那一次扫描的最大值决定**。本机实测（`05_error_bounds.py` §B2）：对称 8-bit、per-tensor min-max、2×10⁵ 样本、100 个不同随机种子，`N(0,1)` 的 SQNR 落在 **[38.18, 40.49]**（极差 2.31 dB），Laplace 落在 **[29.91, 35.20]**（极差 **5.28 dB**）。**成因：`amax` 是样本极值，而极值是小样本统计量。**

> **这也是「per-tensor min-max 的那几格不要逐格引用」的定量依据**——那个数不是一个数，是一个 2–5 dB 宽的随机变量。判据必须写成「N = 多少、per-tensor 还是 per-channel、多少个种子」。

**（2）粒度改变的是「谁的 amax 决定谁的 Δ」。** per-tensor 用整张量的极值给所有元素定 Δ；per-channel 每列一个。本文的界对两者都成立，**但界的宽度不同**（因为 Δ 不同）。这条是下一篇 `06-granularity` 的主线，这里只留一个数：同一个 8 位对称量化器在列 outlier 场景下，per-channel 比 per-token 多 **20.89 dB**（§5 引用，判据见 02）。

**（3）每个比特买到 6.02 dB，但有 H 修正。** 把代价模型写成解析式（判据：per-tensor min-max 对称 RTN、受限量程 `[−QMAX, QMAX]`、`QMAX(b) = 2^(b−1) − 1`、`N(0,1)`、2×10⁶ 样本）：

```
SQNR(b) = 10·log10(12) + 20·log10( QMAX(b) / amax )
```

本机实测与解析式**吻合到 0.005 dB**（b = 3/4/6/8/10/12 六个点，§5 表 2）。注意这是一个**不含 1.76 的式子**——`1.76` 是满量程正弦特有的，一般信号下常数项由 `amax/σx` 决定。

斜率不是常数：`b=3→4` 是 **7.359 dB/bit**，`b=6→8` 是 **6.125**，`b=10→12` 是 **6.027**——**收敛到 6.02，但小 b 处偏陡**，因为 `QMAX = 2^(b−1) − 1` 而不是 `2^(b−1)`。工程含义：**低位宽下「再加一位」的收益略高于 6 dB**。

**（4）`b=2` 时模型失效。** 解析式给 **−3.262 dB**，实测 **0.170 dB**，差 **+3.432 dB**。原因是 `QMAX(2) = 1`，只有三个级数，Δ²/12 的前提（级数多）不成立。**这一类「公式在小 b 处崩掉」是低位宽实践中真实存在的边界，不是数值噪声。**

## 3. 实现与演进

**第一步：裁剪到 max（GEMMLOWP 的做法）。** 直接令 `Xm = max|x|`。它的错误方向很明确：`Δ = 2α/2^M`，舍入噪声 ∝ `α²/(3·2^{2M})`——**α 越大 Δ 越大**。为了不让任何一个值越界而把量程开到最大，等于让其余所有值一起用一套粗格点。SmoothQuant 给出的等价说法是：**非 outlier 通道的有效量化级数会低到 2–3 级**。

**第二步：解析最优裁剪（ACIQ）。** Banner 等（arXiv:1810.05723v3）把 `MSE(α) = 量化噪声 + 裁剪失真` 写成闭式并求极小。Laplace(0,b) 下的论文印值是 `α* = 2.83b / 3.89b / 5.03b`（M = 2/3/4 位）。

> ⚠ **这三组数与「本机数值解」是两档，不得并列成同一个量。** 本文用下面这个目标函数独立做数值最小化（判据必须写出，否则这个数没有意义）：
> `MSE(α) = (1 − P(|X|>α))·Δ²/12 + 2∫_α^∞ (x−α)²·Laplace(0,b)(x)dx`，`Δ = 2α/2^M`，`b = 1`
> 得到 **2.813 / 3.882 / 5.021**，与论文印值分别差 **0.60% / 0.21% / 0.18%**（§A6）。差异来自目标函数的细节（Δ 的定义、尾部积分的近似）。**引用时写「论文印值 2.83/3.89/5.03」；要给本机数值解就另标一档。**
>
> 另外：这三组数在本次检索里**没有拿到独立佐证**（只确认了 ACIQ 的框架：解析裁剪、最小化量化噪声与裁剪失真的权衡）。正文按引用值处理。

**换代价**：`α*` 对应的饱和概率 `P(|X|>α*) = e^(−α/b)`（换算是研究员自算、论文未印）——4 位 **0.65%**、3 位 **2.04%**、2 位 **5.90%**。**位宽越低，最优解越愿意牺牲更多饱和去换更小的 Δ。** 本机复核了 `e^(−α/b)` 这一步的算术（§A6）。

**收益的引用值**（Banner Table 2，8W3A ImageNet Top-1）：ResNet50 **5.6% → 60.8%**、InceptionV3 **34.1% → 56.8%**。
> ⚠ **本文实现者的二次检索未能佐证这两个增量**（检索摘要只命中同名的其它表格）。引用时必须带这句限定语。

**不能写的东西**：「max 裁剪的 MSE 是 α* 裁剪的 N 倍」这个具体倍数。计划基线的控制者测得 Laplace 5.56× / 高斯 3.17×（M=4），审查者测得 4.63× / 2.38×——**不具备跨实现的可复现性**。本文只写「差数倍」与定性方向。

## 4. 踩坑与失败模式

### 4.1 把两种 SQNR 口径拼着用（偏高正好 6 dB）

**现象**：文档写「`SNR = 6.02B + 10.8 − 20log10(Xm/σx)`，其中 `σx = Xm/√2` 时退化成 1.76」。这句话**读起来完全自洽**，代数上却把两个口径的零件拼在了一起。

**成因**：`10.8` 属于**跨度**口径（它的退化条件是 `σx = Xm/(2√2)`），`σx = Xm/√2` 属于**峰值**口径。代入 B=8：

```
6.02×8 + 10.8 − 20·log10(√2) = 48.16 + 10.8 − 3.0103 = 55.95 dB
```

比正确值 49.93 高 **6.02 dB**——恰好是 `20·log10(2)`，也就是两个跨度的比值。本机把这个错值跑了出来（§C2）：**混用版本退化出的常数项是 7.79，不是 1.76**。

**规避**：**判据是「两种口径都必须能退化到 `6.02B + 1.76`」**。写一般式时把 `Xm` 指什么写在公式同一行；写不出退化条件就说明口径没定。这条检查能机械地抓住这个错——上面那个错值的常数项离 1.76 有 6 dB。

### 4.2 把 Δ/2 界用到越界的数据上

**现象**：参数标着「8 位、误差 ≤ Δ/2」，实际部署时输入分布漂移，出现远超 Δ/2 的误差，而监控指标看不出来。

**成因**：**Δ/2 界的前提是「输入不越界」**。一旦某个值落在量化范围之外，它被 saturate 到端点，误差改由「到最近饱和点的距离」决定，**不再有上界**。本机实测（§C1，2×10⁶ 样本）：

| 位宽 | 量程 | 输入范围 | `max|e|/(Δ/2)` | 超过 Δ/2 的样本 |
|---|---|---|---|---|
| 3 | ±1 | ±2 | **8.0** | 43.8% |
| 8 | ±1 | ±1.5 | **128.0** | 33.1% |
| 8 | ±1 | ±10 | **2304.0** | 90.0% |

**规避**：把「越界比例」当成一等监控指标。注意 **Δ/2 界是双边紧的**（实测比值恰好 1.000000），所以它一旦被违反，违反的幅度直接告诉你漂移了多少——`max|e|/(Δ/2)` 是一个很好的告警量。

### 4.3 把浮点的 SQNR 结论套到定点上（P8）

**现象**：读到「SQNR 只和位宽有关，跟分布没关系，跨分布波动约 1 dB」，于是按 `6.02B + 1.76` 给一个 8 位定点量化器排预算，然后在激活那一侧掉 11 dB。

**成因**：**那句话是浮点的，不是定点的。** 浮点的 `1 dB` 来自格式自带的对数刻度；定点的量程由 `amax` 决定，`amax/σx` 直接进公式。实测对照见 §1 第六步：**定点 15.52 dB，浮点 1.02 dB**。

**规避**：**凡讨论 `6.02n+1.76` 是否适用，第一句先写「定点」还是「浮点」。** 这是本文最容易被读者踩的一条，因为它不是「错」，而是**两句都正确的话被贴到了对方的位置上**（CONTRIBUTING 说的 P8）。

### 4.4 忘了 Δ²/12 的四条假设

**现象**：用 `Δ²/12` 估误差功率，在某个模块上估偏好几倍。

**成因**：四条假设里有两条最容易破：**误差在 `[−Δ/2, Δ/2]` 内均匀**、**误差与信号不相关**。本机实测三个反例（§C4）：

| 输入 | `Var(e)/(Δ²/12)` |
|---|---|
| 恒等于 0.2（正好落在网格中央） | **0.0000** |
| 均匀落在 `[0, 0.1]`（远小于一个步长） | **0.1597** |
| 相干采样正弦（每周期恰好 1000 点） | **0.9172** |

**规避**：先问「步长小、信号复杂、未过载」这三条成不成立。DC 附近、极窄动态范围、与采样率共振的周期信号都会破。**真实网络的激活通常是「复杂」的，所以 Δ²/12 大体可用——但这是经验，不是定理。**

### 4.5 把「截断是舍入的两倍」当成方差的两倍

**现象**：文档写「截断的误差是舍入的两倍」，读者按方差理解，把噪声功率乘 2，实际应该是乘 4。

**成因**：「两倍」是在**幅度**（峰值 Δ vs Δ/2、RMS Δ/√3 vs Δ/√12）这个口径下说的；**方差是 4 倍**。本机实测 RMS 比 = 2.001。

**规避**：单位写清楚（「峰值是两倍」「RMS 是两倍」「方差是四倍」三选一，不要写「误差是两倍」）。同一段里另外两个容易并列的量：**偏置是 Δ/2，峰值是 Δ**——它们都「是 Δ 的某个倍数」，但判据不同。

## 6. 小结与延伸

三条可复用的结论：

1. **Δ/2 是精确的、Δ²/12 是近似的，两者差着一整套假设。** 前者只用「最近」这个词，后者要四条（本文 §4.4 给出三个真的跑出来的反例）。工程上的分界线是：**用来做最坏情况设计时看 Δ/2，用来做噪声预算时看 Δ²/12，并且先检查那四条。**
2. **`6.02n + 1.76` 的适用域是「满量程正弦」，不是一个通用定律。** 一般形式有两个自洽口径（跨度 `10.8` / 峰值 `4.77`），**判据是「两者都必须退化成 1.76」**。而对一般信号，更该用的是 `SQNR(b) = 10log10(12) + 20log10(QMAX/amax)`——它显式地带着 `amax`，也就是**把「这个信号有多难量化」写进了公式**，本机实测与它吻合到 0.005 dB。
3. **同一个 `6.02n+1.76` 的问题，定点与浮点是两套答案。** 定点跨分布 **15.52 dB**，浮点跨分布 **1.02 dB**。**讨论这条公式之前必须先说清是哪一种量化器**，否则两句都正确的话会互相打架。

**这条主线在 §0.8 的三角上是哪条边**：本文落在**「范围 vs 精度」**这条边上——给定 b 个比特，`amax` 选多大就是在「不越界」和「分辨率」之间选一个点，而 §3 的 clipping 正是这条边上的显式最优化。

延伸有三条。**往下**：把 8 位放宽到 4 位、2 位时，上面那个解析代价模型在 `b=2` 处**失效**（差 3.4 dB），因为「级数多」这个前提破了——低位宽不是高位宽的简单外推（[03-outliers-and-propagation](07-outliers-and-propagation.md) §1 会给出「2-bit 是质变」的引用值）。**往旁边**：本文一直在假设「一个 Δ 管一张张量」，而**粒度**就是打破这个假设的方式——per-token / per-channel / per-group 各自把谁的 `amax` 拿去定谁的 Δ（[02-granularity](06-granularity.md)）。**往硬件**：Δ/2 界要变成真实 silicon 上的数字，得先知道累加器有多宽、scale 在哪一级应用——那在 [17-kernel-design](17-kernel-design.md)（本文不复述，此处回链）。
