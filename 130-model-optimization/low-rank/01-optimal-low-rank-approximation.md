# 最优低秩逼近：定理只在单位不变范数上成立，而收益由谱决定

> 「秩 `r` 的最优逼近是截断 SVD」这句话**有前提**：最优性只对**单位不变范数**
> （Frobenius、谱范数）成立；换到工程上常用的**逐元素最大范数**，它可以被一个简单的秩 `r`
> 矩阵**严格打败**（程序 C.2：`A = I₂`、`r = 1` 时 `1.000` vs `0.500`）。
> 而更影响决策的是另一半：**同样参数预算下，低秩在指数衰减谱上比 int4 量化省 1575× 误差，
> 在平坦谱上却输 8.69×**（程序 B.1）——低秩的前提是**谱衰减**，不是「矩阵低秩」。

## 0. 背景与动机

把一层权重 `W ∈ ℝ^{d_out×d_in}` 换成两个小矩阵 `W ≈ U V`（`U: d_out×r`、`V: r×d_in`），
是六族优化里唯一**同时减少参数量与 FLOPs** 的一族。它带来两句常被引用的话：

1. 「**低秩逼近的最优解是截断 SVD**」——用它来论证「我们用了 SVD，所以是理论最优」；
2. 「**低秩能压缩权重**」——用它来论证「所以能把模型压小」。

两句都需要限定语，本文把限定语写出来：

| 被引用的话 | 缺的限定语 | 后果（本程序的推导值） |
|---|---|---|
| 「截断 SVD 最优」 | **只在单位不变范数下** | 逐元素最大范数下，一个平凡的秩 1 矩阵就把 `max|·|` 误差从 `1.000` 压到 `0.500`（C.2） |
| 「低秩能压缩」 | **只在谱衰减时** | 同样参数预算（0.25）下：指数衰减谱误差 `0.0001`，平坦谱 `0.9354`——差 **13811 倍**（C.1） |
| 「秩越大越好」 | **秩有盈亏平衡点** | 方阵下 `r > d/2` 时双因子的参数**比满秩还多**（C.3）；`(11008, 4096)` 的平衡点是 `r* ≈ 2985`（B.2） |

一句话动机：**低秩的「最优」与「省」是两件独立的事，各自都有一个容易漏掉的前提。**

## 1. 原理

### 第一步：截断 SVD 的定义与两个范数下的最优

设 `A = UΣVᵀ` 是紧 SVD，`σ₁ ≥ σ₂ ≥ … > 0`。秩 `r` 的截断 SVD 是

$$
A_r \;=\; \sum_{i=1}^{r} \sigma_i\, u_i v_i^{\mathsf T}
$$

**Frobenius 范数下的最优性（Eckart–Young–Mirsky）** 可以用 von Neumann 的迹不等式
三步推完。设 `B` 是任意秩不超过 `r` 的矩阵，记 `s_i = σ_i(A)`：

**① 把误差展开成内积：**

$$
\|A-B\|_F^2 = \|A\|_F^2 - 2\langle A,B\rangle_F + \|B\|_F^2,
\qquad \langle A,B\rangle_F = \operatorname{tr}(A^{\mathsf T}B)
$$

**② 用 von Neumann 迹不等式夹住内积。** 对任意两个矩阵，
`⟨A,B⟩_F ≤ Σ_i σ_i(A)σ_i(B)`（奇异值同序配对）。又因 `rank B ≤ r`，
`σ_i(B) = 0 (i > r)`，于是**求和只需到 `r`**；再用一次 Cauchy–Schwarz：

$$
\langle A,B\rangle_F \;\le\; \sum_{i\le r} s_i\,\sigma_i(B)
\;\le\; \Big(\sum_{i\le r} s_i^2\Big)^{1/2}\Big(\sum_{i\le r}\sigma_i(B)^2\Big)^{1/2}
\;=\; \Big(\sum_{i\le r} s_i^2\Big)^{1/2}\|B\|_F
$$

**③ 代回并配方：**

$$
\|A-B\|_F^2
\;\ge\; \|A\|_F^2 - 2\Big(\sum_{i\le r}s_i^2\Big)^{1/2}\|B\|_F + \|B\|_F^2
\;=\; \underbrace{\Big(\|A\|_F^2 - \sum_{i\le r}s_i^2\Big)}_{=\,\|A-A_r\|_F^2}
\;+\;\Big(\|B\|_F - \Big(\sum_{i\le r}s_i^2\Big)^{1/2}\Big)^{2}
\;\ge\; \|A-A_r\|_F^2
$$

最后一步用了「平方项非负」。★ 注意**这里没有用到 `A−A_r` 与 `A_r−B` 正交**——
在一般情形下两者**并不正交**，写证明时不要图省事套勾股定理。
⇒ `A_r` 是 Frobenius 下的最优。（谱范数下的证明用同一思路的算子版本；
EYM/Mirsky 对**一切单位不变范数**成立。★ 注意这个「一切」的边界——它**不含**
逐元素范数，第四步会给出反例。）

### 第二步：误差有一个闭式，不需要真的做差

由 `A − A_r = Σ_{i>r} σ_i u_i v_iᵀ` 与 `{u_i}`、`{v_i}` 的正交性：

$$
\|A-A_r\|_F^2 \;=\; \sum_{i>r}\sigma_i^2,
\qquad
\|A-A_r\|_2 \;=\; \sigma_{r+1}
$$

程序 A.3 把这两条里第一条**逐位对拍**：显式做差 `1.769870e-08` vs 闭式 `1.769870e-08`，
相对差 `5.235e-15`。★ 这条恒等式是后面所有「误差-预算」曲线的计算基础——
它让「秩 `r` 的误差」变成**只看谱**的量，与 `U`、`V` 无关。

### 第三步：参数量账与盈亏平衡点

双因子存的是 `r × d_out` 与 `r × d_in`，所以

$$
\frac{\text{低秩参数}}{\text{满秩参数}}
= \frac{r\,(d_{\text{in}}+d_{\text{out}})}{d_{\text{in}}d_{\text{out}}}
\;\Longrightarrow\;
r^* = \frac{d_{\text{in}}d_{\text{out}}}{d_{\text{in}}+d_{\text{out}}}
$$

方阵下 `r* = d/2`；`(11008, 4096)` 下程序 B.2 给出 `r* = 2985.2`，
且 `r = 2984` 时占比 `0.9996 < 1`、`r = 2986` 时 `1.0003 > 1`。
⇒ **秩有上限**：超过它，低秩不是压缩而是**膨胀**（C.3：`r=3085` 时占比 `1.0334`）。

### 第四步：★ 定理的边界——换一个范数就失效

这是本文最该被记住的一步。取

$$
A = I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix},\qquad r=1
$$

- **截断 SVD**：`σ = (1,1)`，取 `A_1 = diag(1,0)`。逐元素最大误差 `max|A−A_1| = 1.000`，
  Frobenius 误差 `1.000`。
- **另一个秩 1 矩阵**：`B = 0.5·𝟙𝟙ᵀ = [[0.5,0.5],[0.5,0.5]]`。
  逐元素最大误差 `max|A−B| = 0.500`（**比 SVD 小一半**），而 Frobenius 误差仍是 `1.000`。

$$
\|A-A_1\|_F = \|A-B\|_F = 1.000,
\qquad
\|A-A_1\|_\infty = 1.000 \;>\; \|A-B\|_\infty = 0.500
$$

**Frobenius 下打平、逐元素下被打败**——这不是「SVD 不够好」，而是 EYM 的适用范围
本来就不含 `max|·|`（它不是单位不变范数）。★ 工程上量化误差、裁剪、溢出判据用的恰恰
常是逐元素口径，所以「我们用了 SVD，所以误差最优」这句话在那些场景里**没有依据**。

### 第五步：★ 收益由谱决定，而不是由「低秩」决定

在**同样的参数预算**下把低秩与 int4 量化放在一起比（程序 B.1）。对齐口径：
int4 的纯载荷占比 `4/16 = 0.25`，方阵下对应 `r = d/4 = 64`（`2r/d = 0.25`）。
`512×512`、同一随机种子下：

| 谱 | 低秩（`r=64`）相对误差 | int4 相对误差 | 谁赢 |
|---|---|---|---|
| 指数衰减 `exp(-0.15(i-1))` | **0.0001** | 0.1067 | 低秩赢 **1575×** |
| 幂律 `i^-1.1` | 0.0588 | 0.1046 | 低秩小胜 1.8× |
| **平坦**（`σ_i ≡ 1`） | **0.9354** | 0.1076 | **低秩输 8.69×** |

⇒ 两条结论：

1. **低秩的误差完全由谱决定**（第二步的闭式就是这句话的证明）：谱衰减快，截断丢掉的是
   极小分量；谱平坦，`Σ_{i>r}σ_i²` 几乎等于全能量。
2. **量化不依赖谱**：它的误差来自步长 `Δ` 与舍入，与奇异值分布无关。

所以「该用低秩还是量化」的判据里**必须出现谱**——只比较两者的名义压缩率是不够的。

## 2. 执行映射

- **算 SVD 的那一步**：`torch.linalg.svd` 是稠密全谱分解（`O(min(m,n)²·max(m,n))`）；
  权重矩阵动辄 `4096×11008`，全谱代价不可忽略。工业实现用**随机 SVD**
  （`torch.svd_lowrank` / Halko–Martinsson–Tropp）：先做一次 `A·Ω`（`Ω: n×(r+p)`）
  把列空间压到 `r+p` 维，再对那个小矩阵做 SVD——代价从 `O(mn·min(m,n))` 降到
  `O(mn·(r+p))`，代价是**近似**（不再严格最优，误差由 `σ_{r+1}` 之后的谱尾巴控制）。
- **推理时的收益**：`W x` 的一次矩阵乘被换成 `U(Vx)` —— FLOPs 从 `2·d_out·d_in`
  降到 `2·r·(d_out+d_in)`，与参数账**同一个比例**。这是低秩与量化在机制上的关键差别：
  **量化省字节不省 FLOPs，低秩两者都省**（对照 `overview/01` 的判据表）。
- **一个真实量级**：`160-model/glm/02-glm5-architecture.md` 引 GLM-5 报告的字段
  `KV LoRA Dim = 512`（**引用值**，口径见那一篇）——即注意力侧低秩的潜维取 512。
  ★ 它是**某一代的规格**，不是本文的推导，也不是「所有模型的合适秩」；
  本文能给的只有**判据**：秩要先看谱、再看盈亏平衡点。

## 3. 实现与演进

**朴素做法：全 SVD + 截断。** 数学上最优（在单位不变范数下），代价是
`O(min(m,n)²·max(m,n))`；对一层 `4096×11008` 的权重，这一步比一次前向还贵得多。

**主流做法：随机 SVD。** 用随机投影把问题降到 `(r+p)` 维，把代价压到近线性；
代价是**不再精确最优**，且引入一个必须调的量（过采样 `p` 与幂迭代次数）。
这一步之所以必要：**分解本身的开销必须小于它省下的推理开销**，否则离线压缩的时间
会吃掉收益。

**为什么还需要下一步：把「分解」放进训练里。** LoRA 走的是另一条路——**不分解已训练好的
权重，而是直接训练增量** `ΔW = BA`（`B: d_out×r`、`A: r×d_in`）。
它的账与本文同源（参数量 `r(d_in+d_out)`），但目标是**少存优化器状态**而不是压缩推理；
具体实现与档位在 `peft/`（未开始），本文只给秩的判据。

**前沿方案：不预先固定秩。** 让秩在训练中增长/裁剪（AdaLoRA 一类的思路），
本质是把第三步那个 `r*` 从**常数**变成**被优化的变量**。

## 4. 踩坑与失败模式

### 4.1 现象：把「低秩最优」引成「逐元素误差最优」，量化/裁剪阶段对不上

**成因**：EYM 只覆盖**单位不变范数**（第四步给了 `A = I₂` 的反例：
逐元素口径下 `0.500 < 1.000`）。工程上关心 `max|·|` 的地方——溢出判据、逐元素裁剪、
以及「最大偏差」类的验收条件——这条定理**不适用**。

**规避**：引用时写出范数名字。要逐元素口径，就得自己构造或搜索
（程序 C.2 的两行构造就是一个现成反例）。

### 4.2 现象：按 Frobenius 误差选了一个秩，下游精度却很差

**成因**：Frobenius 误差是**全谱的平方和**，大奇异值方向上的相对偏差可能很小，
而下游敏感的方向（少数几个大奇异值方向）偏差可能很大——两个口径在**谱平坦**时背离最远
（C.1：`0.9354` vs 衰减谱的 `0.0001`）。

**规避**：同时看 `σ_{r+1}`（谱范数误差，即**最坏方向**的误差）而不只是
`Σ_{i>r}σ_i²` 的平方根。判据：若 `σ_{r+1}/σ_1` 不小（例如 > 见 §5 的阈值），
Frobenius 的小误差不能保证下游。

### 4.3 现象：低秩分解后参数反而变多

**成因**：秩超过盈亏平衡点 `r* = d_in·d_out/(d_in+d_out)`（第三步）。
方阵下就是 `r > d/2`；`(11008, 4096)` 下是 `r > 2985`。
C.3 的推导值：`r=3085` 时占比 `1.0334 > 1`。

**规避**：先算 `r*` 再选秩；把它写进配置校验。**低秩不是「秩越小越好」，
也不是「能分解就省」**——它有一个由形状决定的硬上限。

### 4.4 现象：对谱平坦的矩阵做低秩，误差几乎不降

**成因**：第二步的闭式。谱平坦时 `Σ_{i>r}σ_i² ≈ (n−r)σ²`，与全能量
`nσ²` 同阶 ⇒ 相对误差 `≈ √(1−r/n)`，只有「少存 `r/n` 比例的维度」这点收益。
C.1 的推导值：平坦谱 `0.9354` vs 衰减谱 `0.0001`。

**规避**：先看谱再决定用不用低秩。判据见 §5 第一行。

## 5. 判据表

| 条件（可机械判定） | 结论 |
|---|---|
| 要引用「截断 SVD 最优」 | 只对**单位不变范数**（Frobenius / 谱范数）成立；逐元素范数下存在更好的秩 `r` 矩阵（C.2 的 `I₂` 反例） |
| 要选秩 `r` | 先算平衡点 `r* = d_in·d_out/(d_in+d_out)`；`r > r*` 时低秩**比满秩还大** |
| 权重谱衰减慢（`σ_{r+1}/σ_1` 与 `1` 同阶） | **不要用低秩**：同预算下 int4 量化的误差更小（B.1 的平坦谱那一行） |
| 权重谱快速衰减（指数型） | 低秩在同预算下可优于量化多个数量级（B.1：`1575×`），且**同时省 FLOPs** |
| 报低秩的误差 | 写清范数：`Σ_{i>r}σ_i²` 的平方根是 **Frobenius** 误差；`σ_{r+1}` 是**谱范数**（最坏方向）误差 |
| 验收条件是「最大偏差」 | 用 `max|·|` 自己搜一个秩 `r` 矩阵，别假设 SVD 就是最好（C.2） |
| 要在训练里用低秩（LoRA 类） | 参数量账与本文同一个式子；但目标是**省优化器状态**，不是压缩推理 ⇒ 见 `overview/02` 的归因表 |
| 要把低秩与量化**组合** | 顺序可交换性有判据，见 `overview/03`；本文与 `overview/03` 都**没有**覆盖「低秩∘量化」的顺序（未测） |

## 6. 小结与延伸

- 截断 SVD 在 **Frobenius / 谱范数**下是秩 `r` 最优；换到逐元素最大范数**不是**（`I₂` 反例）。
- 误差有闭式：`‖A−A_r‖_F² = Σ_{i>r}σ_i²`、`‖A−A_r‖_2 = σ_{r+1}`。
- 参数量 `r(d_in+d_out)`；平衡点 `r* = d_in·d_out/(d_in+d_out)`，超过它**参数变多**。
- **低秩的收益由谱决定**：同预算下指数衰减谱赢 int4 量化 `1575×`，平坦谱输 `8.69×`。
- 低秩与量化的机制差别：**量化省字节不省 FLOPs，低秩两者都省**。
